## TOOL 2: The Hub-as-Dashboard Template Extension

**Purpose:** Extend your existing Hub template (Chapter 4, Tool 1) to include output sections for each platform. The Hub becomes not just the *input* document but the *complete editorial dashboard*—source material at the top, finished spokes at the bottom. One document. One source of truth. No version confusion. Ever.

**Time needed:** 10 minutes to add the sections to your template. 2 minutes per sprint to paste outputs.

### The New Workflow Rule

**Before (old way):**
- Generate in AI tool → copy to Buffer → realize you need to tweak → go back to AI tool → copy again → Buffer version is now different from your notes → which one is final? → panic → start over

**After (new way):**
- Generate in AI tool → paste into Hub Spoke section → triage and edit IN THE HUB → when final, copy from Hub to scheduler → Hub is always the canonical version → no confusion → ever

**The rule:** *The Hub is the only place where a "final" version of an asset lives. Schedulers get a copy. The Hub keeps the original. If you need to update an asset, you update it in the Hub first, then re-copy to the scheduler.*
