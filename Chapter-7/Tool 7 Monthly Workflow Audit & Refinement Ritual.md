## Tool 7: Monthly Workflow Audit & Refinement Ritual

**Purpose:** To prevent tool creep and prompt drift from undermining your unified workflow over time. This 15‑minute monthly ritual keeps the pipeline frictionless.

**Instructions:** Schedule a recurring 15‑minute block on your calendar (e.g., the first Monday of each month). Each audit, run through the checklist below, then perform a quick end‑to‑end spot test if any issues are flagged.

### Monthly Audit Checklist

**Part A: Tool & Prompt Check**

- [ ] **Tool changes:** Have any of my scheduling tools changed their interface or import format since last audit? If yes, test with a dummy post and update Output Format instructions if needed.
- [ ] **Prompt drift:** Have I noticed any recent AI outputs requiring more manual formatting than usual? If yes, open the prompt template and tighten the output instructions. Run a quick single‑output test.
- [ ] **Hub template integrity:** Is my Hub‑as‑Dashboard template still current? Are the Spoke sections being used consistently, or have I slipped back into saving outputs elsewhere?
- [ ] **New platforms:** Have I added any new platform to my roster? If yes, create a Hub Spoke section, a prompt template, and an integration pathway for it today.
- [ ] **Scheduling tool usage:** Am I still using all my scheduling tools, or have some become inactive? If a tool is unused, consider removing it to reduce subscription costs and mental clutter.

**Part B: End‑to‑End Spot Test (if any issues flagged)**

Take a small, recent Hub and run a mini‑sprint for one platform (Twitter). Time from prompt to scheduled post. Target: under 15 minutes total with zero manual reformatting. If it fails, diagnose and fix before leaving the audit.

**Refinement Principle:** Every friction point you fix in the audit is a permanent gain. The workflow doesn’t just stay unified; it gets tighter.
