## Tool 6: Your Unified Workflow Diagram Template

**Purpose:** To create a visual map of your new, streamlined workflow that shows the Hub at the center, the prompts, the sprint, and the direct feeds into scheduling tools. This becomes your operating blueprint and a training aid if you ever bring on a team member.

**Instructions:** Using your preferred tool (pen & paper, a digital whiteboard, or even a slide), create a clean diagram with the following elements. Annotate with time estimates. Print and post it near your workspace.

### Diagram Elements (suggested layout)

```
                          [PILLAR CONTENT]
                                |
                          [HUB (5 Blocks)]
                         /    |    \    \
        [Twitter Prompt] [LinkedIn Prompt] [TikTok Prompt] [Newsletter Prompt]
               |               |                |                |
        [AI Generates Thread] [AI Gen Carousel] [AI Gen Script] [AI Gen Draft]
               |               |                |                |
         [TRIAGE & LIGHT EDIT – within Sprint]
               |               |                |                |
     [Hub Spoke: Twitter Final] [Hub Spoke: LinkedIn Final] [Hub Spoke: TikTok Final] [Hub Spoke: Newsletter Final]
               |               |                |                |
        [Schedule via Buffer] [Schedule via Later] [Save to recording folder] [Import to Substack]
```

Add boxes for the Hub Spoke sections, the scheduler-ready output format steps, and any automated connectors you might later build (Zapier, etc.).

**Time annotations:** Write the estimated time next to each arrow or phase. The total should reflect your end‑to‑end test time.

**Visual legend:** Use colors or shapes to indicate “Human action,” “AI generation,” “Template/Prompt,” and “Scheduling tool.”

**Post‑diagram reflection:** Compare this to your diagnostic map from Tool 1. How many handoffs disappeared? What’s the new total time versus the old? Celebrate the delta.
