## 3. Scheduler-Ready Prompt Extensions (Fill-in Templates)

For each platform, add an “Output Format” section to your existing prompt templates from Chapter 5. These instructions tell the AI exactly how to format the draft so it can be pasted directly into your scheduling tool with zero manual reformatting.

### 3.1 Twitter/X Thread – Scheduler-Ready Extension

Copy and paste this block into the end of your Twitter Thread Prompt Template.

```
OUTPUT FORMAT FOR SCHEDULER:
- Output as plain text. No markdown, no numbering, no hashtags.
- Each tweet on its own line, with a single blank line between tweets.
- The first line must be the hook tweet (under 140 characters if possible).
- Do not wrap tweets in quotes or add any introductory text.
- This output will be pasted directly into [Buffer / Later / Hootsuite]'s bulk upload or thread composer.
- If the thread would exceed the platform's character limit for a single tweet, suggest a split with a "…" where appropriate, but keep it natural.
```

*Customization:* If you use Buffer’s bulk upload .txt file, adjust to “Output exactly as a .txt file content: one tweet per line, no blank lines—just line breaks.” If you use Hootsuite CSV, adjust to “Output as CSV rows with columns Date, Time, Message. Leave Date and Time blank.”

### 3.2 LinkedIn Carousel – Scheduler-Ready Extension

```
OUTPUT FORMAT FOR LINKEDIN SCHEDULER:
- Output a clear slide-by-slide script. For each slide, write:
  [Slide X]: Headline in square brackets, then body text on the next line.
- Separate each slide block with a blank line.
- Include any visual notes in parentheses: (visual: bold text overlay "The 65% Drop").
- The caption that goes above the carousel in LinkedIn should be the first block, labeled [Main Post Caption].
- This output will be used to paste into [Later / Hootsuite] after uploading the slide images.
- Do not use markdown beyond the bracketed slide labels.
```

### 3.3 Newsletter – Scheduler-Ready Extension

```
OUTPUT FORMAT FOR EMAIL PLATFORM:
- Output the subject line first, on its own line, prefixed with "Subject: ".
- Then the body in clean HTML paragraphs (<p>...</p> tags) OR plain text with double line breaks between paragraphs (specify your email tool's preference).
- Keep it ready for direct copy-paste into [Substack / ConvertKit / Mailchimp].
- No markdown. If plain text, use a single blank line between paragraphs.
```

After customizing for your tools, test once by pasting the output into your scheduler and verifying the preview. Adjust a single line in the prompt if spacing or formatting is off. You'll only do this once per platform.
