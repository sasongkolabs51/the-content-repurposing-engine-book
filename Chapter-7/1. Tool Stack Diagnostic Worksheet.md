## 1. Tool Stack Diagnostic Worksheet

**Purpose:** See exactly where you’re losing time to manual handoffs, reformatting, and app-hopping. Draw the map, then target the three worst friction points.

**Instructions:** Start with the moment your pillar content exists (e.g., a finished video file or transcript). Draw a bubble for every tool or app you open until the post is live on each platform. Label each arrow with the action you take and an estimated time. Be ruthless—include every copy-paste, every manual reformat, every file export.
