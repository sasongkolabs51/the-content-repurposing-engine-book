## Tool 1: The Current Workflow Diagnostic Map

**Purpose:** To see, in one painful but honest picture, every tool and handoff you currently touch between finishing a pillar piece and publishing a repurposed asset. This map surfaces the hidden friction you’re about to eliminate.

**Instructions:** On a large sheet of paper, a whiteboard, or a digital canvas (Miro, FigJam, even a Google Slide), draw a circle for every tool you touch in your repurposing process. Include everything: transcription, notes, AI chat, scheduling, design, storage. Then draw arrows between the circles, and label each arrow with the action you take and an estimated time cost.

### Step‑by‑Step

1. **List all tools you currently use** in the repurposing flow. Include even the “quick” ones—Notion, Descript, Google Docs, ChatGPT, Claude, Buffer, Later, Hootsuite, Canva, native platform schedulers, email platform, etc.

2. **Draw the sequence.** Start from “Pillar content published” (or raw transcript) and end at “Post live on platform.” Place each tool as a circle and connect them with arrows showing the flow.

3. **Label each arrow** with:
   - Action (e.g., “copy transcript,” “paste into prompt,” “reformat line breaks,” “export CSV,” “manually add visual cues”)
   - Estimated time (minutes)
   - Any frustration note (e.g., “always lose formatting here,” “forget which version is latest”)

4. **Circle the top three pain points**—the handoffs that consume the most time or cause the most mental friction. These are your immediate targets for the unified workflow.

**Post‑Diagnostic Reflection:**  
- How many *round‑trip handoffs* did you find (content leaves a tool and returns later, requiring context‑holding)?  
- Which tool do you open the most times during a single repurposing session?  
- If you could wave a magic wand and eliminate one type of handoff entirely, which would it be?
