## TOOL 6: The Monthly Workflow Audit Checklist

**Purpose:** A 15-minute monthly ritual that keeps your pipeline clean, your prompts calibrated, and your tool stack from creeping back into chaos. Schedule it alongside your content calendar review.

**Time needed:** 15 minutes. First Monday of each month. Calendar invite. Non-negotiable.

---

### MONTHLY WORKFLOW AUDIT — [Month / Year]

---

#### Part A: The End-to-End Test (10 minutes)

Run a quick test with a dummy Hub (or reuse last month's Hub).

- [ ] Generate a Twitter thread using scheduler-ready prompt. Paste into scheduler. Format correct? ☐ Yes ☐ No → Fix: _______________
- [ ] Generate a LinkedIn carousel script. Paste into scheduler / Canva workflow. Format correct? ☐ Yes ☐ No → Fix: _______________
- [ ] Generate a newsletter section. Paste into email platform. Format correct? ☐ Yes ☐ No → Fix: _______________

**Any formatting breaks?** ☐ No ☐ Yes → What: _______________

**Prompt updated to fix?** ☐ Yes ☐ N/A

---

#### Part B: Tool Stack Check (3 minutes)

- [ ] Am I still using only my planned tools? (List: _______________)
- [ ] Did I add any new tools this month? ☐ No ☐ Yes → What: _______________ Why: _______________
- [ ] Did any tool update its interface and break my formatting? ☐ No ☐ Yes → Which: _______________ Fix: _______________
- [ ] Is there a tool I'm paying for but no longer using? ☐ No ☐ Yes → Which: _______________ → Cancel? ☐ Yes ☐ Not yet

**Tool creep status:** ☐ Clean ☐ Minor creep (addressed) ☐ Major creep (needs intervention)

---

#### Part C: Hub-as-Dashboard Check (2 minutes)

- [ ] Am I consistently pasting final outputs into Hub Spoke sections? ☐ Always ☐ Usually ☐ Sometimes ☐ Rarely
- [ ] Is the Hub still my single source of truth? ☐ Yes ☐ No → Where else are versions living? _______________
- [ ] Are old Hubs archived or cluttering my workspace? ☐ Clean ☐ Needs archiving → Archive Hubs older than: _______________

---

#### Part D: Sprint Health Check (2 minutes)

- [ ] How many sprints did I run this month? _____ (target: 4)
- [ ] Average sprint time: _____ minutes (trend: ☐ Faster ☐ Same ☐ Slower)
- [ ] Any sprints skipped? ☐ No ☐ Yes → Why: _______________
- [ ] Did I run any Microsprints? ☐ Yes (___) ☐ No
- [ ] Is the sprint still on my calendar as a recurring event? ☐ Yes ☐ No → Re-add it.

---
