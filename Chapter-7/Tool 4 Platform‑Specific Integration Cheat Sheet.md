## Tool 4: Platform‑Specific Integration Cheat Sheet

**Purpose:** A quick reference for the most common integration pathways and tips for Buffer, Later, and Hootsuite, based on real creator workflows. Adapt these to your own stack.

### Buffer

- **Twitter Threads:** Use Buffer’s “Bulk Upload” with a plain‑text file (one tweet per line). Prompt should output each tweet on its own line, blank lines separating them. Avoid markdown.
- **LinkedIn Posts:** Straight copy‑paste into Buffer’s composer works fine if your prompt outputs the final caption. For carousels, upload the PDF/document directly on LinkedIn via Buffer’s media uploader and paste the caption. Note that Buffer’s carousel support may vary; check current capabilities.
- **Tip:** Use Buffer’s “Queue” feature to fill empty time slots automatically. Generate a batch of evergreen threads to keep the queue full.

### Later

- **LinkedIn Carousels:** Upload images (created in Canva) to Later’s media library, then attach the caption generated by your prompt. Your prompt should output a slide‑by‑slide script so you can match images to text.
- **TikTok/Reels:** Later’s “Create Post” supports video upload with caption. Your prompt can output the caption and text overlays separately. Use Later’s “Best Time to Post” suggestions for scheduling.
- **Tip:** Use Later’s “Saved Captions” feature to store frequently used hashtags or calls‑to‑action; reference them in your prompt to include automatically.

### Hootsuite

- **Bulk CSV Import:** For Twitter threads, prompt can output a CSV with columns: Date, Time, Message, Link. Leave Date/Time blank for manual scheduling. Import via “Bulk Composer.” For other platforms, you can import single posts with caption.
- **Multi‑Platform Drafts:** Hootsuite’s composer lets you draft for multiple platforms simultaneously. Use your unified prompt outputs to copy into each platform’s draft tab.
- **Tip:** Use Hootsuite’s “Content Library” to store approved post templates. Your Voice‑Preserving Prompts can be stored as post templates with placeholders.
