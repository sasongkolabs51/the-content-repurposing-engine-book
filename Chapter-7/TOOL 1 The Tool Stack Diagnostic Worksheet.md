## TOOL 1: The Tool Stack Diagnostic Worksheet

**Purpose:** Map your current workflow with ruthless honesty. See every tool, every handoff, every format translation. Find the three biggest friction points. These are your immediate targets.

**Time needed:** 20–25 minutes

**What you need:** A blank sheet of paper (or a digital whiteboard like Miro, FigJam, or even a blank Google Doc). A timer. Your actual workflow from last week's repurposing session.

---

### Step 3: Identify the Friction Types

For each handoff, classify the friction:

| Handoff | Friction Type |
|---|---|
| | ☐ **Round-trip** (content leaves Tool A, comes back later in different format) |
| | ☐ **Format-translation tax** (reformatting to fit Tool B's import requirements) |
| | ☐ **Version confusion** (which copy is the latest? where did I save it?) |
| | ☐ **Context switch** (opening a new app, remembering where things are) |
| | ☐ **Manual data entry** (typing the same info into multiple tools) |
| | ☐ **Character/format limits** (tool truncates or breaks the formatting) |

### Step 5: The "Ideal Flow" Sketch

Now draw (or describe) what the workflow WOULD look like if those three friction points were eliminated:

**My ideal pipeline (minimum steps):**

```
[Hub Document] → [AI Prompt + Generation] → [Triage/Edit in Hub] → [Scheduler]
     ↑                                                                    ↓
     └────────────── [Published Post] ←──────────────────────────────────┘
```

**Tools in my ideal pipeline:**
