## 5. End-to-End Workflow Test Checklist

Run this test after building your scheduler-ready prompts and Hub dashboard to confirm the entire pipeline works. Use a real Hub you've already populated.

- [ ] **Hub ready:** All five input blocks are filled; final Spoke sections are empty but waiting.
- [ ] **Prompt templates updated:** Each core prompt now includes the Output Format extension specific to my scheduling tool.
- [ ] **Sprint executed:** Parallel generation burst, triage, and light edit completed. All final drafts pasted into the Spoke sections of the Hub.
- [ ] **Scheduler test – Twitter:** Copied the final thread from Hub and pasted into scheduling tool. Verified line breaks, character counts, and thread integrity. (No manual reformatting needed—if needed, adjust prompt Output Format and regenerate.)
- [ ] **Scheduler test – LinkedIn:** Copied the main caption and slide text into scheduling tool (or slide creation tool). Formatting matched expectations.
- [ ] **Scheduler test – Newsletter:** Pasted subject line and body into email platform. Previewed; looked correct.
- [ ] **Timing logged:** From start of sprint to all assets scheduled: ___ minutes. Target is under 75 minutes total (60-min sprint + 15 min scheduling). If over, identify the bottleneck and tighten that step.
- [ ] **Cleanup:** Any flagged-for-rewrite assets have a note for later; all final versions are saved in the Hub.

Repeat this test whenever you change scheduling tools or add a platform.
