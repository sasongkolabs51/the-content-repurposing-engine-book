## 7. Workflow Diagram Template

**Purpose:** Create a clean, one-page visual of your unified workflow. Use this as a reference, a reminder, and a training tool if you ever onboard a team member.

**Instructions:** Draw (digitally or on paper) a diagram with the following elements. Then annotate with estimated times.

**Central Node:**  
`HUB (Input: Core Thesis, Stories, Data, Objections, Quotes)` → surrounded by spokes.

**Left side – Input:**  
`[Pillar Content Recording]` → `[Transcription Tool]` → (extract) → `Hub`

**Right side – Output:**  
`Hub` → (feed blocks) → `[Voice-Preserving Prompt Library]` → (parallel generation) → `[AI outputs draft Spokes]` → (triage & edit) → `Hub Spoke Sections` → (copy) → `[Scheduling Tools: Buffer/Later/Hootsuite]` → `[Published]`

**Below diagram, add a simple key:**  
- Blue arrows = automated or prompt-driven  
- Orange arrows = manual but time-boxed (triage)  
- Green = final one-click schedule  

**My Time Estimates:**  
- Hub population: ___ min  
- Sprint (generation + triage): ___ min  
- Paste into scheduler: ___ min  
- Total from recording to scheduled: ___ min  

Post this diagram where you can see it during your sprint.
