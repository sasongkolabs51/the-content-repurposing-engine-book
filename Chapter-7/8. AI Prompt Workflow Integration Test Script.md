## 8. AI Prompt: Workflow Integration Test Script

Use this prompt when you want to test your entire scheduler-ready setup at once, or when you need to quickly verify that your formatting instructions are working across platforms.

```
You are my unified workflow tester. I will provide a sample Hub with all five blocks. Your task is to generate final, scheduler-ready outputs for Twitter, LinkedIn, and my newsletter, using my voice and platform rules exactly as defined below.

[PASTE YOUR CONDENSED VOICE CONSTRAINTS BLOCK FROM CHAPTER 5]

=== TWITTER THREAD ===
[PASTE YOUR FULL TWITTER PROMPT TEMPLATE INCLUDING THE OUTPUT FORMAT SECTION]

=== LINKEDIN CAROUSEL ===
[PASTE YOUR FULL LINKEDIN PROMPT TEMPLATE INCLUDING OUTPUT FORMAT]

=== NEWSLETTER ===
[PASTE YOUR FULL NEWSLETTER PROMPT TEMPLATE INCLUDING OUTPUT FORMAT]

Hub for testing:
[PASTE A REAL HUB]

Generate all three outputs. After each one, include a brief note if there are any formatting elements that might cause copy-paste issues for my scheduling tool.
```

Use this monthly during the audit. It catches formatting drift before it wastes real sprint time.
