## 6. Monthly Workflow Audit Checklist

Schedule 15 minutes per month (e.g., the first Monday) to keep your pipeline frictionless.

- [ ] Run a test sprint with a dummy Hub. Use all scheduler-ready prompts.
- [ ] Paste each output into its respective scheduling tool. Check for any formatting anomalies: unexpected line breaks, character limits exceeded, CSV misalignment.
- [ ] For each issue found, update the corresponding Output Format prompt instruction. Fix once; it’s fixed for all future sprints.
- [ ] Review your tool map from Section 1. Have any new handoffs crept in? Have any tools changed their import formats?
- [ ] Are you still using all tools you pay for? Cancel subscriptions for tools you no longer need.
- [ ] Check the Spoke sections in recent Hubs. Are all finals stored there? If not, re-anchor the habit.
- [ ] Update the Scheduler-Ready Output Format Cheat Sheet if any tools or formats changed.
- [ ] Reflect: “What’s the single biggest friction point left in my workflow?” Write it down and schedule a 10-minute block to design a fix.
