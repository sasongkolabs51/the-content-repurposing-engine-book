### The Prompt Assembly Formula

Every AI prompt you write from this point forward follows this structure:

```
[ROLE] + [VOICE FINGERPRINT] + [PLATFORM RULES] + [HUB BLOCKS] + [INTENT] + [OUTPUT FORMAT]
```

| Component | Source Document | What It Provides |
|---|---|---|
| Role | (Written in prompt) | "You are my structural adaptation engine…" |
| Voice Fingerprint | Chapter 2 document | Hook style, rhythm, vocabulary, structure, register |
| Platform Rules | Chapter 3 Playbook | Format, length, native conventions, anti-patterns |
| Hub Blocks | This chapter's document | The actual content: thesis, stories, data, objections, quotables |
| Intent | (Written in prompt) | What this specific asset should DO for the reader |
| Output Format | (Written in prompt) | Numbered tweets, slide-by-slide, timestamped script, etc. |

**The rule:** If any of the three documents is missing from the prompt, the output will be generic. All three must be present. Every time.

### Quick-Link Setup (Do This Now)

In your Hub template, at the very top, add:

```
LINKED DOCUMENTS:
→ Voice Fingerprint: [paste URL or file path]
→ Platform-Format Playbook: [paste URL or file path]
→ This Hub's Spoke Tracker: [paste URL if you use one]
```

If you use Notion: create a "Content System" database with three linked databases (Hubs, Voice, Playbooks). Every Hub page auto-links to the other two.

If you use Google Docs: create a "Content System" folder with three subfolders. Every Hub doc has a header with hyperlinks to the Voice Fingerprint doc and the Playbook doc.

If you use Obsidian: use `[[wikilinks]]` to connect your Hub note to your Voice Fingerprint note and your Playbook note. The graph view becomes your system map.
