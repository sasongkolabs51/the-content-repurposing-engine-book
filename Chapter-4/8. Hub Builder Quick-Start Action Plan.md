## 8. Hub Builder Quick-Start Action Plan

**Purpose:** A single-session walkthrough to go from no Hub to a working Hub-and-Spoke Command Center.

**Total time:** Roughly 1 hour (but you can split it over two days).

- [ ] **Minute 0–5:** Duplicate the Hub Template from Section 2. Name it for your most recent pillar piece.
- [ ] **Minute 5–10:** Gather your raw material: open the transcript or notes for that pillar.
- [ ] **Minute 10–35:** Use the Hub Building Walkthrough Worksheet (Section 3) to populate all five blocks. If you prefer, use the AI Hub Builder Assistant prompt (Section 7) first, then edit the output into the template.
- [ ] **Minute 35–40:** Run the Quick-Access Test (Section 4). Tweak labeling if anything took too long to find.
- [ ] **Minute 40–45:** Complete the Hub Integration Checklist (Section 5): add links to your Voice Fingerprint and Platform-Format Playbook.
- [ ] **Minute 45–50:** Scan the Hub Health Troubleshooting Guide (Section 6) and fix any obvious issues.
- [ ] **Minute 50–60:** Reflect. Write a single sentence at the top of your Hub: “This is the single source of truth for [Pillar Title]. All repurposing starts here from now on.”

**Tomorrow:** When you sit down to repurpose, open this Hub—not the transcript, not six tabs. Notice what shifts.
