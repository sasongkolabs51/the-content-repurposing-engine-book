## Tool 3: The Hub Quality Quick‑Access Test

**Purpose:** To verify that your Hub is truly modular and retrieval‑ready—not just a slightly tidier transcript. If you can’t pull the components you need in under 60 seconds, your formatting or level of detail needs work.

**Instructions:** After populating a Hub, set a 60‑second timer and attempt the following scavenger hunt. Don’t scroll; use the headings to jump.

### Scavenger Hunt

| Task | Found? (✓/✗) | If not found, what was missing? |
|------|--------------|--------------------------------|
| Locate a statistic that could anchor a LinkedIn carousel. | | |
| Locate a personal story suitable for a newsletter opening. | | |
| Locate a quotable line that could be a Twitter hook. | | |
| Locate an audience objection and your response that would make a strong carousel slide. | | |
| Identify the Core Thesis in under 10 seconds. | | |

**Score:** ___ / 5 found within 60 seconds.

**If you scored below 4:**  
- Check that each block is clearly separated by its heading.  
- Make sure stories are fully written out, not just tagged as “the judge story.”  
- Ensure data points are standalone sentences with attribution, not embedded in paragraphs.  

Make adjustments to your Hub until you consistently score 5/5. The point is not neatness; it’s speed of retrieval when you’re sprinting in Chapter 6.
