## 5. Hub Integration Checklist

**Purpose:** Ensure your new Hub is properly connected to the other two core components of the Content Transformer system so that every prompt you build later is fully armed.

- [ ] Link to **Voice Fingerprint** (from Chapter 2) added to Hub template or embedded directly in this Hub.  
- [ ] Link to **Platform-Format Playbook** (from Chapter 3) added or embedded.  
- [ ] The five block headings exactly match the labels you plan to use in AI prompts (consistent naming helps the AI parse correctly).  
- [ ] All data points, quotes, and stories are on separate lines, not buried in paragraphs.  
- [ ] Personal notes, tangents, and editorial musings *not* meant for the AI are removed or placed in a separate “Notes” section at the bottom, clearly labeled “Do Not Include in Prompts.”  
- [ ] File naming convention decided: e.g., “Hub – Decision Fatigue Detox – 2024-07” so you can find any Hub instantly.
