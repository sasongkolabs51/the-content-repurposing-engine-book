### DAY 2 PROMPT: THE STORY

```
ROLE: [Your Role]
VOICE: [Paste Fingerprint]
PLATFORM RULES: [Paste]

CONTENT TYPE: Personal (override detection)
CONDITIONAL LOGIC: Personal branch rules.

HUB: Key Story #[X] (the most personal one) + Quotable Line #[X]

TASK: Tell the personal story that gave birth to the insight.
Narrative arc: setup → lowest moment → realization. NO framework.
NO numbered steps. Pure story.

HOOK PATTERN: [Mid-Scene Drop / Vulnerability Ledger]
EMOTIONAL PEAK: The lowest moment. Let the reader sit in it.
CLOSE: A quiet realization. Not a solution. A "and that's when
I understood…" beat.

[PERSONAL INSERT]: I will add the specific sensory details
after generation. Leave a [PLACEHOLDER] for the exact words
someone said / the exact feeling in the room.

OUTPUT: The asset. [DIRECTOR'S NOTE]: flag the [PLACEHOLDER]
spots for my "yes, and" intervention.
```

### DAY 4 PROMPT: THE OBJECTION

```
ROLE: [Your Role]
VOICE: [Paste Fingerprint]
PLATFORM RULES: [Paste]

CONTENT TYPE: Contrarian (override detection)
CONDITIONAL LOGIC: Contrarian branch rules.

HUB: Audience Objection #[X] + Counter + Data Point #[X]

TASK: Address the primary counterargument. Start with the
objection in the audience's voice. Validate it. Then dismantle
it with evidence and nuance. Concede what's true about it.

HOOK PATTERN: [Contrarian Cliffhanger / Diagnostic Question]
STRUCTURE: "But wait—" → Objection stated fairly → Evidence
against → Concession ("And look, they're not entirely wrong…")
→ Reframe
CLOSE: Invite debate. "I could be wrong. But I don't think I
am. What do you think?"

OUTPUT: The asset. [DIRECTOR'S NOTE]: flag where to add a
personal "I used to believe this too" admission.
```

### DAY 5 PROMPT: THE REFLECTION

```
ROLE: [Your Role]
VOICE: [Paste Fingerprint]
PLATFORM RULES: [Paste]

CONTENT TYPE: Personal (override detection)
CONDITIONAL LOGIC: Personal branch. Reflective, processed
vulnerability. NOT raw. "I've been through it. Here's what
I see now."

HUB: Core Thesis (reframed as question) + Quotable Line #[X]
+ Original Commentary

TASK: Close the arc. Look back on the week's idea. Share what's
changed since you first formulated it. Invite the audience into
conversation. This is a letter, not a broadcast.

HOOK PATTERN: [Quiet Confession / Curiosity Gap]
TONE: Warm. Open-ended. Slightly uncertain. "I don't have a
clean answer. But I have a better question."
CLOSE: A genuine invitation. "Hit reply. Tell me your version.
I read every one."

OUTPUT: The asset. [DIRECTOR'S NOTE]: flag where to add a
personal "here's what I'm still figuring out" admission.
```
