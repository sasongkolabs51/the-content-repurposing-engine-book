## TOOL 3: The Daily 5-Minute Tune-Up Card

**Purpose:** The end-of-day micro-ritual that catches small issues before they compound. Three questions. Five minutes. Every workday. So lightweight that skipping it feels unnecessary.

**Time needed:** 5 minutes. Set a recurring phone alarm for end of workday.

---

### DAILY TUNE-UP — [Date]

*(Do this at your desk. Standing up. Coffee in hand. Five minutes. Then close the laptop.)*

---

**Question 1: Did anything post incorrectly today?**

☐ No issues. All clear.
☐ Yes → What: _______________
  - Formatting glitch? ☐ Yes → Fix prompt Output Format block.
  - Broken link? ☐ Yes → Fix in scheduler.
  - Missing image/visual? ☐ Yes → Add to pre-sprint checklist.
  - Wrong platform? ☐ Yes → Check scheduler settings.
  - Character limit exceeded? ☐ Yes → Tighten prompt constraint.

**Is this the first time or a repeat?**
☐ First time → Note it. Watch for recurrence.
☐ Second time → **Fix the prompt template NOW.** (2 min. Do it before you close the laptop.)

---

**Question 2: Did any post get an unusual response?**

☐ No. Normal engagement.
☐ Yes, positive spike → Which post: _______________
  - What might explain it? (Hook? Topic? Timing? Platform algorithm?)
  - → Flag for Exemplar Loop (Chapter 8, Tool 6). Add to next monthly review.

☐ Yes, negative / confusing response → Which post: _______________
  - What happened? (Criticism? Confusion? Silence?)
  - Possible cause: ☐ Voice drift ☐ Tone mismatch ☐ Hook-context mismatch ☐ Bad timing ☐ Other: ___
  - → Note for Weekly Data Whisper. Investigate if pattern emerges.

---

**Question 3: What's one thing I'll do differently tomorrow?**

_______________________________________________________________

*(Examples: "Add a negative example to my LinkedIn prompt." / "Run a microsprint instead of full sprint because afternoon is packed." / "Swap the Reference Example for Twitter—last week's thread outperformed it." / "Nothing. The system ran clean today.")*

---

**Tune-up complete. Close the laptop. Go live your life.**

---

### The Compound Effect

After 30 days of daily tune-ups, you'll have made ~30 micro-adjustments. After a year, ~250. Each one is tiny. Together, they transform your system from "the one I built in a weekend" to "the one that's been refined by 250 small acts of attention." No quarterly overhaul needed. No "content strategy day" that never happens. Just five minutes a day, compounding quietly.
