## 11. 30‑Day Flywheel Installation Calendar

**Purpose:** A day‑by‑day plan to install all the habits from this chapter. Start on any Monday.

**Week 1 – Establish the Rhythm**
- **Day 1:** Set up your Flywheel Autopilot (Worksheet 1). Block your Sprint Window and Hub‑Building Block in your calendar as recurring events.
- **Day 2:** Build the Sprint Launchpad (Template 2). Bookmark it and set the “Sprint in 10” reminder.
- **Day 3:** Run your first sprint with the Launchpad. Use the Pre‑Sprint Checklist for the first time.
- **Day 4:** Do your first Daily 5‑Minute Tune‑Up (Checklist 4). It will feel small; that’s the point.
- **Day 5:** Run your second sprint or a microsprint. Notice any friction and update the Launchpad.
- **Day 6:** Complete your first Weekly Data Whisper (Log 5). Update matrix scores.
- **Day 7:** Rest. The system is already moving.

**Week 2 – Layer in Resilience**
- **Day 8–14:** Continue daily tune‑ups and your sprint. This week, deliberately simulate a “missed sprint” scenario (or if one happens naturally, good). Use the Resilience Protocol Card to run a microsprint or restore an archive post.
- **End of Week 2:** Second Weekly Data Whisper. Add your first row to the Progress Evolution Tracker.

**Week 3 – Add Voice Monitoring**
- **Day 15–21:** Continue all rhythms. At the end of the week, run your first Monthly Voice Check (Scorecard 6). Use the AI Voice Drift Detector (Prompt 10.2) as a helper.
- Start the One Percent Rule Log (Template 9). This week’s improvement: the voice‑drift fix you identified, if any.

**Week 4 – Close the Loop**
- **Day 22–30:** Continue all rhythms. At the end of the month, conduct a mini Quarterly External Audit (even if it’s early—ask a friend for a 5‑minute look). Reflect using the Quarterly Reflection Prompt (10.3).
- Review your Progress Evolution Tracker. Celebrate the sprint‑time drop, the asset‑count rise, the smoother flow.

**Day 31+:** The flywheel is installed. Maintain the Weekly Data Whisper, Monthly Voice Check, and Daily Tune‑Up. The system now runs mostly on autopilot.
