## TOOL 1: The Sprint Launchpad

**Purpose:** A single page (physical or digital) that holds everything you need to start a sprint in under sixty seconds. No searching. No deciding. No "where did I save that prompt?" You open the launchpad. You follow the checklist. You sprint.

**Time needed:** 15 minutes to set up. 60 seconds to use per sprint.

#### The Sprint Phases (Glance During Sprint)

```
[0:00–0:05]  FIRE all prompts. Don't read outputs yet.
[0:05–0:35]  TRIAGE. Max 10 min per asset. Approve / Edit / Flag.
[0:35–0:50]  POLISH. Read all keepers. Add personal layer.
[0:50–0:60]  SCHEDULE. Copy from Hub → paste to scheduler. Queue.
```

#### If I Can't Do the Full Sprint Today:

☐ **Microsprint** (15 min): One platform. Top-scoring Hub. Generate → triage → schedule.
☐ **Archive Restore** (5 min): Resurface a proven evergreen post. Requeue.
☐ **Intentional Pause**: Post one "I'm taking a brief pause" message. Rest. Return when ready.
