## How to Use This Toolkit

These aren't decorative PDFs you download, admire, and forget. They're working documents. Print them, scribble on them, tear pages out, tape them above your desk. Each one maps directly to a shift you made in Chapter 1. Work through them in order the first time. After that, they become your weekly operating rhythm.

You'll need about 90 minutes for the full first pass. Block the time. Close the tabs. This is the unglamorous foundation work that makes everything in Parts 2–4 actually stick.
