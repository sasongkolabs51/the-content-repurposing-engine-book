## 6. AI Prompt Templates for Platform‑Native Content

These prompts assume you’ve already built a Hub (a structured document with thesis, stories, data, objections, quotes, etc.). Use them to generate first drafts that are structurally faithful to each platform and infused with your voice mechanics. Fill in the bracketed sections with details from your Hub and your Voice‑as‑System Inventory.

### 6.1 LinkedIn Carousel Prompt

```
You are an editorial director creating a LinkedIn carousel.  
Use the following voice mechanics:  
- Open with a surprising, short declarative sentence that challenges a common belief.  
- Use a conversational tone with contractions and direct address (“you”, “your”).  
- Structure slides as a narrative arc: problem → hidden truth → evidence → practical framework → reflective question.  
- Slide texts should be concise, under 25 words each.  

Hub components to draw from:  
[Core thesis]  
[Supporting story #2]  
[Audience objection]  
[A data point or counterintuitive insight]  

Generate a 7‑slide carousel outline. Include a slide‑by‑slide breakdown with the headline for each slide and a brief note on the visual idea.
```

### 6.2 Twitter/X Thread Prompt

```
You are a creator known for threads that build unbroken curiosity.  
Voice mechanics:  
- Hook tweet: blunt, counterintuitive statement or personal admission (under 140 characters).  
- Each subsequent tweet ends on a pattern interrupt—a question, a cliffhanger, or a bold promise that the next tweet fulfills.  
- Mix short, punchy lines with a rare longer tweet for a data reveal.  
- Final tweet: reflective question that invites replies, no hard CTA.  

Hub components:  
[Core thesis]  
[Quotable line]  
[Supporting story #1]  
[Audience objection]  

Write a 10‑tweet thread that translates these into a high‑retention narrative. Number the tweets.
```

### 6.3 TikTok / Reels Script Prompt

```
Write a 60‑second vertical video script for a creator who uses high‑energy, visual language.  
Voice mechanics:  
- First 1.5 seconds: a bold physical action or visual metaphor with on‑screen text that creates a curiosity gap.  
- Pattern: “You know how [common situation]? Well, the real reason is [insight].”  
- Use a single, personal mini‑story as evidence.  
- End with a loop‑able twist or challenge that encourages rewatching.  

Hub components:  
[Core thesis reframed for a general audience]  
[Story #1 condensed to 3 sentences]  
[Audience objection debunked in one line]  

Provide the script with visual cues and estimated timing for each segment.
```

### 6.4 Newsletter Introduction Prompt

```
You are writing the opening of a weekly newsletter that feels like a letter from a smart, slightly irreverent friend.  
Voice mechanics:  
- Start with a personal, vulnerable hook (an “I noticed…” or “I’ve been thinking about…”).  
- Bridge from the personal to the universal problem your pillar addresses.  
- Tease the main insight without giving everything away—create a knowledge gap.  
- Use a tone that’s warm, direct, and free of marketing jargon.  

Hub components:  
[Core thesis]  
[The personal story that led to this insight]  
[One quotable line]  

Write a 150‑word newsletter introduction. It should make the reader feel seen and compel them to read the full piece or watch the video.
```
