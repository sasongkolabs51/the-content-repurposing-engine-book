## 8. The 60-Minute Timer Breakdown

Use this as a visual guide for where your minutes go. Adjust for 90-minute batch sprints proportionally.

| Phase | Time | What Happens |
|-------|------|--------------|
| **Preflight** (before timer) | 0:00–0:03 | Run through checklist, set up tabs, set timer. |
| **Parallel Generation Burst** | 0:00–0:05 | Paste Hub blocks into all prompts and submit. |
| **Triage – Twitter** | 0:05–0:15 | Approve, Lightly Edit, or Flag. Move on. |
| **Triage – LinkedIn** | 0:15–0:25 | Same. |
| **Triage – TikTok/Reels** | 0:25–0:35 | Same. |
| **Triage – Newsletter** | 0:35–0:45 | Same. (Adjust if newsletter is longer; trim other triages slightly.) |
| **Light Final Polish & Schedule** | 0:45–0:55 | Quick read-through of all Approved/Lightly Edited drafts. Fix obvious typos. Copy into scheduler. |
| **Wrap-up & Flag Follow-up** | 0:55–0:60 | Note any prompt adjustments for next sprint. Move flagged assets to Rewrite folder with a note. |

**If you finish early:** Use remaining time to flesh out flagged assets or refine your prompt templates. Never start a new task.
