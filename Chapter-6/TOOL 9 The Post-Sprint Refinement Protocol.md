## TOOL 9: The Post-Sprint Refinement Protocol

**Purpose:** Handle the flagged assets and the "almost there" drafts without blowing up your schedule. This is the 15–20 minute block you do later in the day (or the next morning) to close the loop on anything the sprint didn't finish.

**Time needed:** 15–20 minutes. Separate from the sprint. Different energy.

#### The Fix Process (for each flagged asset)

**Step 1:** Read the failure note. What specific constraint was missing?

_______________________________________________________________

**Step 2:** Open the prompt. Add the missing constraint. (Use the Failure Diagnostic Guide from Chapter 5, Tool 6.)

**Step 3:** Regenerate. ONE attempt. Score it quickly (Voice + Format, 1–5).

**Step 4:** If score ≥ 4: approve. Add personal layer. Queue it.
If score < 4: make one more prompt adjustment. Regenerate once more.
If still < 4 after two attempts: rewrite manually (10 min max). Or skip this asset this week.

#### The Personal Layer Insertion

For EVERY asset (approved, lightly edited, or regenerated), confirm:

☐ I added at least one element that ONLY I can write:
- A specific personal memory
- A timely cultural reference (something that happened THIS week)
- A reader callback ("Last week, [name] asked me…")
- A line I'm slightly nervous to post (the honest one)
- An ad-lib / improvised phrase that feels alive

**If I didn't add this layer, the asset is 80% done but 100% generic. Add it now.**
