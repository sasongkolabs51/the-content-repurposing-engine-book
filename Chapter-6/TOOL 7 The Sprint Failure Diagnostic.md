## TOOL 7: The Sprint Failure Diagnostic

**Purpose:** When a sprint goes sideways—and it will, occasionally—use this to diagnose the specific failure mode and apply the targeted fix. Don't spiral. Don't conclude "the system doesn't work." Just find the broken gear and replace it.

**Time needed:** 5 minutes post-sprint.

#### Failure Mode 1: Prompt Drift

**The symptom:** Two or more outputs are significantly below your tested quality. The voice is off, the structure is wrong, or the AI missed the thesis.

**Diagnosis questions:**

☐ Was the Hub content substantially different from what I tested the prompts on? (More emotional? More nuanced? Different topic area?)
☐ Did I forget to update the Voice Fingerprint or Playbook rules in the prompt?
☐ Was the Reference Example still relevant, or has my style shifted since I last updated it?

**The fix:**

_______________________________________________________________
*(e.g., "Added a tone note for emotional content: 'This topic is personal. Increase vulnerability register to 50%. Allow longer sentences in the story beat.'")*

**Prompt updated?** ☐ Yes ☐ Not yet → Do it before next sprint.

---

#### Failure Mode 2: The Overshoot

**The symptom:** The timer hit 0:00 and you'd only triaged two platforms. You got sucked into editing one asset for 20+ minutes.

**Diagnosis questions:**

☐ Did I skip the triage framework and start line-editing immediately?
☐ Did I set a subtimer for each asset (8 min max)?
☐ Was I trying to make one asset "perfect" before moving to the next?
☐ Was I anxious about publishing something that wasn't 100%?

**The fix for next sprint:**

☐ Set a physical subtimer: 8 minutes per asset. When it rings, I STOP. Even mid-sentence.
☐ Write this on a sticky note and put it on my monitor: **"TRIAGE, DON'T PERFECT. You are a doctor sorting patients, not a surgeon operating on one."**
☐ Reduce the sprint to 3 assets instead of 4 until the rhythm is re-established.
☐ Schedule a separate 15-minute "polish block" later in the day for the asset I over-edited.

#### Failure Mode 3: The Abandoned Sprint

**The symptom:** You skipped the sprint for 2+ weeks. The old manual pattern crept back in. You feel guilty.

**Diagnosis questions:**

☐ Did life genuinely intervene (illness, travel, crisis)? → No fix needed. Just restart.
☐ Did the sprint feel like "one more chore" on an already overloaded week?
☐ Did the sprint block keep getting bumped by "more important" tasks?
☐ Did I lose faith in the system after one bad sprint?

**The fix:**

☐ **Run a Microsprint** (Tool 8). Just one platform. Fifteen minutes. Prove the system still works.
☐ **Lower the bar.** Next sprint: 2 assets instead of 4. Build back up.
☐ **Move the sprint to a better time.** If Tuesday mornings are chaos, try Thursday afternoons.
☐ **Tell someone.** A friend, a community, an accountability partner. "I sprint every [day] at [time]." External commitment beats internal willpower.
☐ **Forgive yourself.** The system is resilient. It's designed to be picked back up. You didn't "fail." You paused. That's different.

Platform: _______________
Full sprint resume date: _______________

#### Failure Mode 4: The Quality Drop

**The symptom:** You're hitting the time targets, but the outputs feel generic. Voice scores are 3/5. You're publishing content you're not proud of.

**Diagnosis questions:**

☐ Am I skipping the polish phase to save time?
☐ Have I stopped adding my "human layer" (the personal anecdote, the timely reference)?
☐ Is my Voice Fingerprint outdated? Has my voice evolved since I last updated it?
☐ Am I using the same Reference Example for too long?

**The fix:**

☐ Protect the 15-minute polish phase. It's not optional. It's where the 20% human layer goes in.
☐ Schedule a Voice Fingerprint refresh (Chapter 2, Tool 9).
☐ Swap the Reference Example for a recent high-performer.
☐ Add one "personal insertion point" per asset that I MUST fill in during polish. No AI can write it. Only I can.
