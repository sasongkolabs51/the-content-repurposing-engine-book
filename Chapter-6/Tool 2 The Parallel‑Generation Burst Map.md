## Tool 2: The Parallel‑Generation Burst Map

**Purpose:** To make the “parallel” part of the sprint automatic. Instead of re‑reading the Hub mid‑sprint to decide what goes where, you pre‑assign specific blocks to each platform prompt using this map. Fill it once per sprint, then fire all prompts in rapid succession.

**Instructions:** For each platform, put a checkmark next to the Hub blocks you want that prompt to use. Add any special micro‑instructions in the right column.

**Quick rule:** Twitter loves the Core Thesis + Quotable Lines + one Objection. LinkedIn loves a Key Story + a Data Point + the Core Thesis. TikTok needs one punchy Quotable Line as a text overlay + the Core Thesis distilled to two short sentences. Newsletter gets the full Hub with room to expand.

After filling, paste the assigned blocks into each prompt tab. Work fast—you’re not editing, just pasting. The goal is to have all prompts submitted within five minutes.
