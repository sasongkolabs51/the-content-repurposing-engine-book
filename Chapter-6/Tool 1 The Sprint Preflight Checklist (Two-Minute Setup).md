## Tool 1: The Sprint Preflight Checklist (Two-Minute Setup)

**Purpose:** To eliminate the silent friction that kills sprints before they start—searching for the right prompt, hunting for the Hub, reformatting on the fly. Run this checklist before every sprint; it should take under two minutes once it’s familiar.

**Instructions:** In the two minutes before you start your timer, confirm each item. If anything is missing, fix it now—do not start the sprint with unchecked boxes.

### Preflight Checklist

- [ ] **Hub is sprint‑ready:** All five blocks are filled. Headings match the prompt templates exactly. Data points and quotable lines are on separate lines. Stories are written as complete paragraphs—not bullet-point ghosts.
- [ ] **Prompt library is open and current:** Each platform’s prompt template has today’s Voice Fingerprint block, up‑to‑date structural rules, and the correct reference example. I’ve checked for any rule tweaks I noted after last sprint.
- [ ] **AI tool tabs are set:** One tab per platform (Twitter, LinkedIn, TikTok/Reels, Newsletter). Each tab has the corresponding prompt template pasted in, with a placeholder where I’ll insert the Hub blocks.
- [ ] **Parallel‑generation map is visible** (see Tool 2): I know exactly which Hub blocks to feed into each prompt. No guessing.
- [ ] **Timer is set to 60 minutes** and placed where I can see it easily. (Phone or browser tab—just not hidden.)
- [ ] **Distractions are killed:** Notifications off. Unrelated tabs closed. Phone on Do Not Disturb. Headphones on if that’s your focus cue.
- [ ] **Sprint tracker is open** (Tool 4) to log decisions as I go.

**Sprint start affirmation (optional):** “I’m not creating from scratch. I’m reviewing AI drafts with my editorial brain. Triage, not perfection. Done, not perfect.”
