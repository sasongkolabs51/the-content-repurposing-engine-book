## TOOL 2: The Sprint Phase Tracker

**Purpose:** A visual guide for the 60-minute structure. Glance at this during the sprint to know which phase you're in and how much time you should be spending. Prevents the "I looked up and 40 minutes were gone" disaster.

**Time needed:** 0 minutes to use. Just glance.

---

### THE 60-MINUTE SPRINT — PHASE MAP

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  PHASE 1: PARALLEL GENERATION BURST          [0:00 – 0:05]     │
│  ─────────────────────────────────────────────────────────────  │
│  Fire all prompts. Don't wait for one to finish before          │
│  starting the next. Paste Hub blocks → submit → next tab.       │
│  All requests submitted within 5 minutes.                       │
│                                                                 │
│  ⚡ KEY RULE: Do NOT read the outputs yet. Fire and move on.    │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  PHASE 2: TRIAGE PASS                        [0:05 – 0:35]     │
│  ─────────────────────────────────────────────────────────────  │
│  Drafts are returning. Assess each one. Sort into:              │
│  ✅ APPROVE (90%+ ready) → quick read, move on (3 min max)     │
│  ✏️ LIGHTLY EDIT (75–90%) → one structural fix (8 min max)     │
│  🚩 FLAG FOR REWRITE (<75%) → note the failure, move on (1 min)│
│                                                                 │
│  ⚡ KEY RULE: Max 10 minutes per asset. Subtimer if needed.     │
│  ⚡ KEY RULE: You are a triage doctor, not a surgeon.            │
│                                                                 │
│  Asset 1 (Twitter):    ☐ Approve  ☐ Light Edit  ☐ Flag         │
│  Asset 2 (LinkedIn):   ☐ Approve  ☐ Light Edit  ☐ Flag         │
│  Asset 3 (TikTok):     ☐ Approve  ☐ Light Edit  ☐ Flag         │
│  Asset 4 (Newsletter): ☐ Approve  ☐ Light Edit  ☐ Flag         │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  PHASE 3: LIGHT FINAL POLISH                 [0:35 – 0:50]     │
│  ─────────────────────────────────────────────────────────────  │
│  Read through all APPROVED and LIGHTLY EDITED drafts in         │
│  sequence. Check for:                                           │
│  • Voice consistency across all assets                          │
│  • Typos / formatting errors                                    │
│  • Missing platform elements (line breaks, visual cues, etc.)   │
│  • The one personal touch per asset (your "human layer")        │
│                                                                 │
│  ⚡ KEY RULE: Refine, don't restructure. No rewrites here.      │
│  ⚡ KEY RULE: 15 minutes total. Not per asset. Total.           │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  PHASE 4: SCHEDULE / ARCHIVE / NOTE          [0:50 – 0:60]     │
│  ─────────────────────────────────────────────────────────────  │
│  • Copy approved assets into scheduling tool / queue            │
│  • Format for each platform (line breaks, slide design, etc.)   │
│  • Note any FLAGGED assets: what failed, what to fix            │
│  • Quick note: what to refine in prompts for next sprint        │
│                                                                 │
│  ⚡ KEY RULE: Don't start editing flagged assets now. Just      │
│  note them. You'll handle them in the Post-Sprint Protocol.     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Time Checkpoints (Glance During Sprint)

| Time Elapsed | You Should Be… | If You're Not… |
|---|---|---|
| 0:05 | All prompts fired. Waiting for drafts. | You're still setting up. Hurry. |
| 0:15 | Mid-triage. 1–2 assets assessed. | You're editing one asset too long. Flag it. Move on. |
| 0:30 | Triage nearly done. 3–4 assets sorted. | You're still on asset 2. Stop editing. Triage only. |
| 0:35 | Triage complete. Starting polish phase. | You're over. Cut polish to 10 min. Protect Phase 4. |
| 0:50 | Polish done. Starting scheduling. | You're still polishing. Stop. Schedule what's ready. |
| 0:60 | Done. Timer goes off. You stop. | You're not done. That's okay. Note what's left. Stop anyway. |
