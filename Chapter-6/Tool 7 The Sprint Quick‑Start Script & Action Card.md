## Tool 7: The Sprint Quick‑Start Script & Action Card

**Purpose:** A condensed, step‑by‑step action card you can read in 30 seconds before you hit “start” on your timer. Combine with the mental rehearsal script to get your mind into editorial triage mode.

### Quick‑Start Action Card (print or screenshot)

**0:00–0:02** → Run Preflight Checklist (Tool 1). Hub ready, prompts open, tabs set, timer on, distractions off.  
**0:02–0:07** → Paste Hub blocks into each prompt tab using the Parallel‑Generation Map (Tool 2). Submit all.  
**0:07–0:45** → Triage each draft as it arrives (Tool 3). Max 10 min per asset. Approve, Lightly Edit, or Flag. Log decisions in Sprint Tracker (Tool 4).  
**0:45–0:55** → Light Final Polish on approved/edited assets. Read through for voice consistency, typos, missing line breaks. No restructuring.  
**0:55–0:60** → Schedule or archive: queue Twitter, LinkedIn, TikTok script; paste newsletter draft into email platform. Note any flags for prompt adjustment.

### Mental Rehearsal Script (read aloud before first sprint)

*I’m not writing four posts. I’m reviewing four drafts. That’s a completely different creative task—less draining, faster, and more strategic.*

*My job today is triage, not perfection. If a draft is 90% there, I approve and move on. If it’s 75% there, I fix one structural thing and move on. If it’s below that, I flag it and move on. Nothing gets more than ten minutes right now. The timer protects my energy and my output.*

*Parallel generation means I’ve already won. By the time I’m adjusting the first Twitter hook, the LinkedIn carousel is already drafted and waiting. I’m not building each platform sequentially on a depleting brain. I’m directing an assembly line I set up beforehand.*

*If the timer beeps and I’m not finished, I’ll do a quick final pass and stop. The world won’t end if the newsletter goes out tomorrow morning instead of right now. But I will finish this sprint with at least three platform‑ready assets, and that’s a victory I can build on every single week.*

*Let’s sprint.*
