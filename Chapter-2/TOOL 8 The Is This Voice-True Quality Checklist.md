## TOOL 8: The "Is This Voice-True?" Quality Checklist

**Purpose:** A 60-second scan you run on every AI draft before you start editing. Catches the most common voice failures fast, so you're not wasting editing time on a draft that needs a full prompt redo.

**Time needed:** 1 minute per draft
