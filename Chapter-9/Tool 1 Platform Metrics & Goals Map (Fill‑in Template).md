## Tool 1: Platform Metrics & Goals Map (Fill‑in Template)

**Purpose:** To pin down exactly what you want repurposing to achieve on each platform, and which metrics you’ll track. This map then determines the weighting you’ll apply when scoring content for each platform.

**Instructions:** For every platform you actively maintain, fill in a row. Use the suggested defaults if you’re not sure, but adjust them as soon as you have a clearer picture of your business model.

| Platform | Primary Business Goal | Key Metric(s) to Track | Evergreen Weight | Resonance Weight | Shareability Weight | Notes (e.g., “Leads from this platform convert at 3x”) |
|----------|------------------------|------------------------|------------------|------------------|---------------------|------------------------------------------------------|
| Twitter / X | (e.g., Audience growth, top‑of‑funnel discovery) | (e.g., retweets + new follower rate per post) | 20% | 30% | 50% | |
| LinkedIn | (e.g., Lead generation, professional authority) | (e.g., comment depth, DM inquiries, click‑through to landing page) | 30% | 50% | 20% | |
| Newsletter | (e.g., Retention & conversion) | (e.g., open rate, reply rate, click‑through) | 40% | 40% | 20% | |
| TikTok / Reels | (e.g., Brand awareness, top‑of‑funnel) | (e.g., views, new follower rate, shares) | 20% | 20% | 60% | |
| (Other) | | | | | | |

**Weighting Check:** Each row’s weights should sum to 100%. If you later find that high-shareability posts aren’t driving your goal (e.g., course sales), you’ll adjust the weights in your monthly matrix review (Tool 6).
