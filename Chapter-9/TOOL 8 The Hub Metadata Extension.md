## TOOL 8: The Hub Metadata Extension

**Purpose:** Add scoring metadata to the top of every Hub so the matrix data lives alongside the content. When you open a Hub, you immediately see its scores and priority level. No separate spreadsheet to cross-reference.

**Time needed:** 2 minutes per Hub to add.

---

### Add This Block to the Top of Your Hub Template (After the Title, Before Core Thesis)

```
───────────────────────────────────────────────────────
##MATRIX SCORES
───────────────────────────────────────────────────────

Date scored: [YYYY-MM-DD]
Scored by: [Your name / "AI-assisted" / "Post-performance data"]

EVERGREEN STRENGTH: [1 / 2 / 3]
Reasoning: [One sentence. e.g., "Psychology of avoidance—timeless."]

EMOTIONAL RESONANCE: [1 / 2 / 3]
Reasoning: [One sentence. e.g., "Personal burnout story. High vulnerability."]

SHAREABILITY: [1 / 2 / 3]
Reasoning: [One sentence. e.g., "Counterintuitive reframe. Broadly relevant."]

WEIGHTED SCORES:
- Twitter: [___] / 3.0
- LinkedIn: [___] / 3.0
- TikTok: [___] / 3.0
- Newsletter: [___] / 3.0

TOP PLATFORM: [___]
INTENSITY LEVEL: [Full / Standard / Light / Skip]
REPURPOSING STATUS: [Not started / In progress / Complete / Re-repurposable]
LAST REPURPOSED: [Date or "Never"]
DISCOVERY SPRINT NEEDED: [Yes / No]

PERFORMANCE NOTES (update after repurposing):
- [Date]: [Platform] [Asset] → [Key metric result]
- [Date]: [Platform] [Asset] → [Key metric result]
```

---

### The Workflow Integration

**When you build a new Hub:** Score it immediately. Takes 2 minutes. Use the rubric (Tool 2). Don't overthink it. First instinct + rubric criteria.

**When you finish a sprint:** Update the "Performance Notes" section with actual results.

**When you do the Monthly Matrix Review (Tool 6):** Update scores based on accumulated data. Adjust Evergreen if needed. Update Repurposing Status.

**When you plan a sprint (Tool 5):** Sort your Hubs by weighted score. The top-ranked unrepurposed Hub is your default sprint focus.
