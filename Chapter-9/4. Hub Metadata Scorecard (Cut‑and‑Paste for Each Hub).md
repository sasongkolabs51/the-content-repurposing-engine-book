## 4. Hub Metadata Scorecard (Cut‑and‑Paste for Each Hub)

**Purpose:** Embed the three scores directly into your Hub document so that every sprint planning session starts with the numbers, not a vague memory.

**Instructions:** After building a new Hub (Chapter 4), spend two minutes assigning scores. Add this block near the top of the document.

```
### REPURPOSING POTENTIAL SCORES
Date scored: _________
- Evergreen Strength: ___ / 3
- Emotional Resonance: ___ / 3
- Shareability: ___ / 3

Weighted scores by platform (from my Metrics-and-Goals Map):
- Twitter: _______
- LinkedIn: _______
- Newsletter: _______
- TikTok: _______

Notes (e.g., "High resonance but only for a narrow audience segment," "Timely now, but will drop to Evergreen 1 after Q3"):
```

When you review the Hub later for a potential repurposing sprint, these scores will jump out. No need to re‑evaluate from scratch.
