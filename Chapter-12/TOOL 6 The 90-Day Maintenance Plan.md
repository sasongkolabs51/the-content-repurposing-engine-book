## TOOL 6: The 90-Day Maintenance Plan

**Purpose:** The structured bridge between "I finished the book" and "this is just how I operate." Three months of specific, scheduled actions that embed the system permanently.

**Time needed:** 10 minutes to set up. Then it runs on the rhythms you've already built.

#### Days 1–30: Stabilize

*Goal: Run the system consistently. Build the rhythm. Don't optimize yet. Just show up.*

| Week | Focus | Actions |
|---|---|---|
| 1 | Run the flywheel | ☐ Full sprint. ☐ Daily tune-ups (5/5 days). ☐ Weekly Data Whisper. ☐ Set up launchpad. |
| 2 | Run the flywheel | ☐ Full sprint. ☐ Daily tune-ups. ☐ Weekly Data Whisper. ☐ First One Percent improvement. |
| 3 | Test resilience | ☐ Run a microsprint (prove the fallback works). ☐ Archive Restore one evergreen post. ☐ Daily tune-ups. |
| 4 | First review | ☐ Full sprint. ☐ Weekly Data Whisper. ☐ Review Progress Tracker (4 weeks). ☐ Monthly Voice Check. |

**Day 30 checkpoint:**

☐ I ran at least 3 full sprints.
☐ I did the Daily Tune-Up at least 15/20 days.
☐ I ran the Weekly Data Whisper at least 3 times.
☐ I made at least 2 One Percent improvements.
☐ The system feels more automatic than it did on Day 1.

---

#### Days 31–60: Optimize

*Goal: Refine based on data. Run the first Quarterly Optimization Loop. Start the Transformer Circle.*

| Week | Focus | Actions |
|---|---|---|
| 5 | Optimize prompts | ☐ Full sprint. ☐ Review last month's A/B test data. ☐ Update 2 prompt templates. |
| 6 | Build community | ☐ Send Transformer Circle invitations (Tool 4). ☐ Full sprint. ☐ Daily tune-ups. |
| 7 | First Circle meeting | ☐ Run the monthly Circle meeting (or attend one). ☐ Swap one prompt. ☐ Share one failure. |
| 8 | Quarterly Loop | ☐ Run the full **Quarterly Optimization Loop** (Tool 3). 90 minutes. ☐ Update Voice Fingerprint, Playbook, Matrix. |

**Day 60 checkpoint:**

☐ I ran the Quarterly Optimization Loop.
☐ I have a Transformer Circle (or I'm actively building one).
☐ My prompts have been updated based on real data.
☐ My matrix scores are more accurate than they were on Day 1.

---

#### Days 61–90: Amplify and Teach

*Goal: Run a Five-Day Arc. Create your Legacy Action. Compute your Before-and-After metrics. Publish them.*

| Week | Focus | Actions |
|---|---|---|
| 9 | Amplify | ☐ Choose your highest-scoring pillar. ☐ Run a **Five-Day Arc** (Chapter 10). ☐ Voice Drift Audit on all 5 pieces. |
| 10 | Teach | ☐ Plan and create your **Legacy Action** (Tool 5). ☐ Publish it. ☐ Tag it. |
| 11 | Measure | ☐ Compute your **Before-and-After Metrics** (Tool 2). ☐ Write the sharing version. |
| 12 | Celebrate + Plan | ☐ Publish your metrics. ☐ Write your **Manifesto** (Tool 1) if you haven't yet. ☐ Plan next quarter. ☐ Celebrate. Seriously. You did this. |

**Day 90 checkpoint:**

☐ I produced a Five-Day Arc.
☐ I created and published a Legacy Action (teaching piece).
☐ I computed and shared my Before-and-After metrics.
☐ I wrote (or revised) my Content Transformer Manifesto.
☐ I have a plan for the next 90 days.
