## 4. Conditional Logic Builder Template

**Purpose:** Formalize your content type branches so you can paste them into any prompt. Over time, add more types (e.g., “Case Study,” “Rant”) and refine the rules.

| Content Type | Primary Hook(s) | Narrative Arc | Tone Adjustments | Forbidden Moves |
|--------------|-----------------|---------------|------------------|-----------------|
| ANALYTICAL (framework, how‑to) | Specificity Bomb, Insight‑First | Problem → framework → application | Confident, instructive; use “you” sparingly; short sentences | No emotional oversharing; no Confession Opener; no “we’ve all been there” |
| PERSONAL (story, transformation) | Confession Opener, Vulnerability Ledger | Struggle → insight → transformation → lesson | Warm, self‑disclosing, conversational; use “I” heavily; one moment of doubt | No rigid numbering; no jargon; no “optimize” language |
| CONTRARIAN (myth‑busting) | Bold Reframe, Contrarian Cliffhanger | Challenged belief → evidence → reframed perspective | Provocative but not aggressive; invite debate; avoid qualifiers | Don’t open with a statistic unless shocking; don’t use passive voice |
| (Add your own) | | | | |

**Usage:** In each prompt, add the line:  
“CLASSIFY the content into one of these types: [list]. Then apply the matching rules.”
