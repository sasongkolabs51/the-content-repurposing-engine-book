## TOOL 6: The Exemplar Loop Worksheet

**Purpose:** The monthly ritual that turns your best posts into training data for your prompts. This is how your prompt library gets smarter every month instead of stagnating.

**Time needed:** 20 minutes. First Monday of each month. Calendar invite.

---

### MONTHLY EXEMPLAR LOOP — [Month / Year]

---

#### Step 1: Identify Top 3 Performers (5 minutes)

Look at your posts from last month across all platforms. Rank by **engagement rate** (engagement ÷ impressions), not absolute likes.

☐ Same content type? Which: _______________
☐ Same emotional register? Which: _______________

_______________________________________________________________

Based on the pattern, what prompt update will you make?

| Prompt | Update | Reason |
|---|---|---|

| LinkedIn | | |
| Newsletter | | |

**Prompt updated?** ☐ Yes ☐ Not yet → Do it before next sprint.

---

#### Step 5: Rotate Reference Examples (2 minutes)

| Platform | Current Reference Example | Replace With | Content Type Label | Hook Pattern Label |
|---|---|---|---|---|
| Twitter | *(old post)* | *(new top performer)* | ☐ A ☐ P ☐ C | _______________ |
| LinkedIn | | | ☐ A ☐ P ☐ C | _______________ |
| Newsletter | | | ☐ A ☐ P ☐ C | _______________ |

**Archive the old Reference Examples** (don't delete—move to a "Past References" folder in case you need them for pattern analysis later).

---

#### Step 6: Test the Updated Prompt (2 minutes)

Run one quick generation with the new Reference Example and updated prompt. Does the output feel sharper? More aligned with what's working?

☐ Yes, noticeable improvement
☐ Slightly better
☐ No difference → The update might be too subtle. Make it more specific.
