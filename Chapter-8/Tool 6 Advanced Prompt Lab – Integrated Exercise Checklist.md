## Tool 6: Advanced Prompt Lab – Integrated Exercise Checklist

**Purpose:** A step-by-step action plan that walks you through every major exercise from the chapter in a single, focused working session. Treat it like a “lab day” to upgrade your entire prompt library to magnetic.

**Instructions:** Block 90 minutes. Follow the steps in order, checking off as you go.

### Lab Checklist

**Phase 1: Hook Architecture Upgrade (30 min)**
- [ ] Open your 3 core prompt templates (Twitter, LinkedIn, Newsletter).
- [ ] Using Tool 1, replace any vague hook instruction with at least 2 specific hook architectures per platform, complete with Do/Don’t examples from your niche.
- [ ] Insert the “HOOK ARCHITECTURE RULES” prompt block into each template.
- [ ] Run a quick test generation for one platform to ensure the AI follows the hook pattern correctly. Note any adjustments needed.

**Phase 2: Install Conditional Logic (25 min)**
- [ ] Copy the Content Type Detection block (Tool 2) into each prompt template, placing it before platform structural rules.
- [ ] Customize the branch descriptions: replace generic examples with your own voice and platform playbook details.
- [ ] Test with an Analytical Hub and a Personal Hub on the same platform. Check that the AI selected different hooks and tones. Log results in the Conditional Logic Test Log.
- [ ] If differentiation is weak, tighten the branch instructions or add “Bad Example” lines.

**Phase 3: Set Up the Exemplar Loop (15 min)**
- [ ] Schedule a recurring monthly “Prompt Review” calendar event.
- [ ] Populate the Top Performer Analysis and Reference Example Bank (Tool 3) with your most recent data.
- [ ] If you already have a top performer, rotate it into one prompt’s Reference Example right now.
- [ ] Bookmark the Prompt Update Log for future use.

**Phase 4: Plan an A/B Magnetism Test (10 min)**
- [ ] Choose one platform and content type for your first test.
- [ ] Fill out the Test Planner in Tool 5.
- [ ] Set a reminder to check results 48 hours after the second post goes live.
- [ ] Decide in advance: if version A wins, I’ll update my prompt to [action]; if B wins, I’ll [action].

**Phase 5: Complex Scenario Challenge (10 min)**
- [ ] Use Tool 7 to write a full prompt for a sensitive, personal topic (burnout, failure, grief). Focus on emotional intelligence and tone-guarding constraints.
- [ ] Run the prompt against a mock Hub. Note whether the output feels appropriately warm and respectful. Adjust prompt guardrails as needed.
