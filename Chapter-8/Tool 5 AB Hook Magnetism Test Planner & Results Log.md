## Tool 5: A/B Hook Magnetism Test Planner & Results Log

**Purpose:** To run live experiments that validate which hook architectures actually work best for your audience, so your prompts are guided by data, not intuition.

**Instructions:** For a single platform (start with Twitter), plan an A/B test of two hook patterns. Keep all other post elements identical (same Core Thesis, same story, same length). Publish both within a comparable time window (e.g., same day of week, same time, one week apart). Measure and decide.

**Decision:**
- If one clearly outperforms: Update prompt template to prioritize that hook for this content type. Add a note to prompt: “For [content type] content, default to [winning pattern]. Use [losing pattern] only as a secondary option.”
- If results are ambiguous: Run a second test with a different Hub, or test on a different platform.

**Pattern Rotation Reminder:** Even a winning hook can fatigue. Re-test every 2–3 months.
