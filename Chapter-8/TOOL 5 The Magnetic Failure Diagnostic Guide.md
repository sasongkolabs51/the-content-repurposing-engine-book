**Purpose:** When a post falls flat despite your advanced prompts, use this to diagnose the specific failure mode and apply the targeted fix. Every failure is data. Every thud is a lesson.

#### Failure Mode 2: Fatigue Pattern

**The symptom:** A hook that worked for 2–3 months suddenly underperforms. Gradual decline across multiple posts using the same pattern.

**Diagnostic questions:**

☐ Have I used this hook pattern in 4+ consecutive posts?
☐ Are all my Reference Examples using the same pattern?
☐ Has my audience seen this structure enough times to predict it?
☐ Is the pattern still fresh in my niche, or have others adopted it?

**The fix:**

☐ Rotate the hook pattern. Demote the fatigued one for 4–6 posts.
☐ Promote a different pattern to primary.
☐ Update Reference Examples to use a variety of patterns.
☐ Add to prompt: "AVOID [fatigued pattern] for the next [X] posts. Use [new pattern] instead."

**Rotation plan:**

| Post # | Hook Pattern Used | Notes |
|---|---|---|
| Last 4 posts | *(e.g., Specificity Bomb ×4)* | Fatigued |
| Next post | *(e.g., Mid-Scene Drop)* | Fresh |
| Post after | *(e.g., Bold Reframe)* | Fresh |
| Post after | *(e.g., Contrarian Cliffhanger)* | Fresh |
| Return to Specificity Bomb | Post #[X] | Reset |

#### Failure Mode 3: Emotional Flatline

**The symptom:** Decent likes (people found it useful), but very low shares (people didn't feel enough to pass it on). Reads like a well-constructed lecture.

**Diagnostic questions:**

☐ Is there an emotional PEAK in the post? (A moment of vulnerability, surprise, humor, or tension?)
☐ Does the narrative arc build to a feeling, or just to an information delivery?
☐ Is the tone uniformly "instructive" throughout, with no register shift?
☐ Would I share this with a friend? Or just bookmark it?

**The fix:**

☐ Add an emotional peak instruction to the prompt: "In [tweet 3 / slide 3 / paragraph 2], insert a brief personal moment of self-doubt, realization, or humor. The goal is to create an emotional peak that makes the subsequent insight feel EARNED."
☐ Add a register shift: "Shift from authoritative to vulnerable for one beat, then back."
☐ Add a sensory detail: "Include one physical, sensory image that grounds the abstract idea in a body."

**Prompt addition:**

```
EMOTIONAL PEAK REQUIREMENT:
This post must contain at least one moment where the register
shifts from [instructive/confident] to [vulnerable/surprised/
humorous/self-doubting]. This moment should appear in [tweet 3 /
slide 3 / the second paragraph] and last for 1–2 sentences before
returning to the primary register.

The goal: the reader should FEEL something, not just LEARN something.
Information gets bookmarked. Emotion gets shared.
```

#### Failure Mode 4: The "Correct but Invisible" Problem

**The symptom:** The post is voice-true, platform-native, structurally sound, and… nobody notices it. It's polite. It's waiting to be discovered. It doesn't GRAB.

**Diagnostic questions:**

☐ Is the hook *safe*? Does it avoid any risk of being wrong, controversial, or too specific?
☐ Is the first sentence something a hundred other creators could have written?
☐ Am I using the AI's default "reasonable" output instead of pushing for the "slightly too bold" version?
☐ Would I stop scrolling for this hook if I saw it from someone else?

**The fix:**

☐ Add a "push" instruction to the prompt: "Make the hook 20% bolder than feels comfortable. If it feels slightly risky, it's probably right. If it feels safe, rewrite it."
☐ Add a specificity requirement: "The hook must contain at least one oddly specific detail (a number, a time, a name, a physical object) that no generic AI output would include."
☐ Run the prompt TWICE. Use the second output. (The first is often the AI's "safe" answer. The second, after a "make it bolder" nudge, is the magnetic one.)

**Prompt addition:**

```
MAGNETISM OVERRIDE:
After generating the first draft, review the hook. Ask: "Would
THIS hook stop ME from scrolling at 7:42 a.m. while half-awake
on the train?" If the answer is "maybe" or "probably not,"
rewrite the hook to be 20% bolder, 20% more specific, and 20%
more emotionally provocative.

The hook should feel slightly risky. Not offensive. Not clickbait.
But the kind of sentence that makes someone think "you can't just
SAY that" followed immediately by "…but what do you MEAN?"

If the hook feels safe, it's wrong.
```
