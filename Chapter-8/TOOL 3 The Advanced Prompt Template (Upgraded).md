```

═══════════════════════════════════════════════════════

ROLE:
[Your Role statement from Chapter 5]

[Paste your condensed Voice Fingerprint]

HOOK ENGINE:
Based on the detected content type, use the corresponding hook
architecture from my Hook Library:

- If ANALYTICAL: Use Specificity Bomb or Bold Reframe.
  [Paste the relevant hook pattern instructions from Tool 1]

- If PERSONAL: Use Mid-Scene Drop.
  [Paste the relevant hook pattern instructions]

- If CONTRARIAN: Use Contrarian Cliffhanger or Bold Reframe.
  [Paste the relevant hook pattern instructions]

NEGATIVE HOOK RULES (apply to ALL content types):
- NEVER open with a rhetorical question.
- NEVER open with "We've all been there" or any universal statement.
- NEVER open with "In today's world…" or "In today's fast-paced…"
- NEVER open with "Hot take:" or "Unpopular opinion:"
- NEVER open with a statistic unless it's genuinely shocking
  (over 50% deviation from what the reader expects).

[Your existing structural rules from Chapter 5]

[The arc rules from the Conditional Logic Block]

CONSTRAINT — HUB CONTENT:
[Your existing Hub constraint block from Chapter 5]

CREATIVE INTENT:
[Your creative intent for this specific asset]

OUTPUT FORMAT:
[Your scheduler-ready Output Format block from Chapter 7]

OUTPUT:
The numbered tweets. Then:
[DIRECTOR'S NOTE]: Flag 1–2 personal insertion points.
[HOOK DIAGNOSTIC]: State which hook pattern you used and why.
[CONTENT TYPE]: State which type you detected and which rules
you applied.

═══════════════════════════════════════════════════════
END OF PROMPT

```
