## 10. Quick‑Start Action Plan: Upgrade Your Prompts to Magnetic

Set aside 90 minutes.

- [ ] **0–10 min:** Open the Hook Architecture Menu (Section 1). For each platform, circle the 2–3 patterns that feel like you.  
- [ ] **10–25 min:** Fill in the Prompt Hook & Arc Upgrade Worksheet (Section 2) for Twitter and LinkedIn. Write explicit Do and Don’t examples.  
- [ ] **25–40 min:** Open your existing prompt templates (from Chapter 5). Copy and paste in the upgraded hook architectures and negative examples.  
- [ ] **40–55 min:** Using the Conditional Logic Builder (Section 4), add the Content Type Detection block to each prompt. Customize the branches to your content mix.  
- [ ] **55–70 min:** Set up your Initial Exemplar Bank (Section 5). Find at least one high‑performing post per platform per content type. Paste them into your prompt templates as Reference Examples.  
- [ ] **70–85 min:** Generate one test post from a real Hub using the magnetic prompt. Check if the hook reflects the content type appropriately. Adjust if needed.  
- [ ] **85–90 min:** Schedule your first A/B test (Section 6) and your first Monthly Magnetism Review. Write the Identity Anchor on a sticky note and place it near your monitor.
