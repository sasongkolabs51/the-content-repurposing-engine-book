## Tool 1: Hook Architecture Upgrade Worksheet

**Purpose:** To replace vague “start with a good hook” instructions in your prompts with specific, platform-native hook architectures that the AI can execute precisely. This worksheet helps you define, store, and deploy magnetic hooks.

**Instructions:** For each platform you create for, define 2–3 hook patterns using the table below. Fill in a name, a short description, a real example from your niche (or an idealized one), a “Do” (what to do) and a “Don’t” (what to avoid). Then use the prompt insertion block to transplant them into your templates.

### Twitter/X Hook Patterns

| Pattern Name | Description | My Niche Example | Do This | Don’t Do This |
|--------------|-------------|------------------|---------|---------------|
| **Bold Reframe** | State a widely accepted belief and invert it immediately. | “Most productivity advice is written by people who love being productive. That’s the blind spot.” | Start with a statement that sounds counterintuitive but is defensible. | Don’t open with a rhetorical question; don’t soften with “I think…” |
| **Specificity Bomb** | Use an oddly precise number or detail that implies a personal story. | “I tracked 847 decisions last Monday. By 2 p.m., my brain was making choices a random number generator would beat.” | Choose a specific, slightly weird detail that makes the reader need to know more. | Don’t use a statistic without emotional weight; don’t make it generic. |
| **Contrarian Cliffhanger** | State a controversial position and stop, forcing the reader to click for the explanation. | “Decision fatigue isn’t real. At least, not the way you’ve been told.” | End the hook tweet right at the peak of the contradiction. | Don’t explain anything in the hook tweet; don’t add a second sentence. |

### LinkedIn Carousel Hook Patterns

| Pattern Name | Description | My Niche Example | Do This | Don’t Do This |
|--------------|-------------|------------------|---------|---------------|
| **Insight-First Headline** | A single sentence that names a specific professional struggle and implies a framework solution. | “The 3-Part Framework I Use to Reduce Daily Decisions by 60% (Without Killing Spontaneity)” | Be clear about the outcome and the framework. Include a parenthetical that addresses a common objection. | Don’t make it a question; don’t use jargon without defining it. |
| **Vulnerability Ledger** | Open with a personal mistake or painful lesson, then promise the system that prevented it. | “Last year, I made a $15,000 decision on a Tuesday at 4 p.m. while mentally fried. Here’s the system that made sure it never happened again.” | Be honest and specific about the cost. Quickly pivot to the solution. | Don’t overshare without tying it to a universal insight; don’t sound self-pitying. |

### TikTok/Reels Visual-Verbal Hook Patterns

| Pattern Name | Description | My Niche Example (spoken + text) | Do This | Don’t Do This |
|--------------|-------------|----------------------------------|---------|---------------|
| **Contradiction Burst** | Spoken statement contradicts on-screen text or immediate visual. | Spoken: “Stop trying to make better decisions.” / Text overlay: “Seriously. Stop.” | Create a moment of confusion that demands the viewer keep watching to resolve. | Don’t let the spoken and text repeat each other; don’t start with “Hey guys.” |
| **Visual Metaphor Opener** | Show a visual metaphor that instantly conveys the problem. | Show a phone battery at 5%. Spoken: “This is what your brain looks like at 3 p.m.” | Choose a metaphor that doesn’t need explanation. | Don’t talk over the visual without acknowledging it. |

### Newsletter Subject Line Patterns

| Pattern Name | Description | My Niche Example | Do This | Don’t Do This |
|--------------|-------------|------------------|---------|---------------|
| **Curiosity Gap** | Imply a revelation or story without giving it away. | “The day I realized I wasn’t lazy—I was just making too many decisions.” | Create an open loop the reader must close by opening the email. | Don’t make it clickbait that the body doesn’t deliver. |
| **Contrarian Stance** | Challenge a common belief directly. | “Why ‘just prioritize’ is terrible advice (and what to do instead)” | Be bold but accurate. | Don’t attack people; challenge ideas. |

### Prompt Insertion Block

Add this block into your prompt templates immediately after the “Voice Constraints” section:

**HOOK ARCHITECTURE RULES:**

- [Platform] Hook Options: [list the pattern names you’ve defined, with brief descriptions and examples from above].
- For this prompt, use the **[Pattern Name]** hook pattern: [paste its Do/Don’t rules].
- Alternatively, if using conditional logic (Tool 2), select the appropriate hook based on content type.
