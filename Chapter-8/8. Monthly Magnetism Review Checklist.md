## 8. Monthly Magnetism Review Checklist

Schedule 20 minutes each month to keep your prompts sharp.

- [ ] Review your Exemplar Rotation Log. Update the Reference Example in each prompt for any replaced exemplar.
- [ ] Scan your A/B Test Tracker. Are there clear winner patterns? Encode them: e.g., “For Analytical Twitter threads, default to Specificity Bomb unless the Core Thesis explicitly challenges a belief.”
- [ ] Read the last 3 posts that underperformed. Use the Magnetic Failure Diagnostic Card. Update prompt rules accordingly.
- [ ] Check for hook fatigue. If a pattern has been used for 3+ months as primary, rotate it to secondary and promote a new one.
- [ ] Review your Conditional Logic Builder. Any new content types you need? (e.g., “Case Study,” “Curated List”)
- [ ] Add one fresh “Do” example and one “Don’t” example to each prompt, drawn from recent posts (yours or a competitor’s that you want to emulate or avoid).
- [ ] Run one test prompt with a dummy Hub to confirm all changes hold.
