## 7. The Swap Test Worksheet

**Purpose:** Ensure your prompts don’t only work with one piece of content. A robust prompt should produce great output from any Hub.

**Instructions:** Take a Hub from a completely different pillar (different topic, different length, different story types). Without editing the prompt templates (only swapping the Hub content at the bottom), generate one output from each of your three prompt templates.

**Swap Hub title:** ________________________

| Prompt | Voice Accuracy (1–5) | Format Correctness (1–5) | Did scores hold? |
|--------|----------------------|--------------------------|------------------|
| Twitter Thread |                      |                          | ☐ Yes ☐ No       |
| LinkedIn Carousel |                   |                          | ☐ Yes ☐ No       |
| Newsletter |                        |                          | ☐ Yes ☐ No       |

**If scores dropped:**
- Look at the output. Where exactly did it fail?  
- Does your Voice Constraints block contain topic-specific language (e.g., “decision fatigue”)? Generalize it.  
- Do your Structural Rules assume a certain kind of story? Broaden them.  
- Adjust the prompt and rerun the Swap Test until scores hold.

**Once scores hold:** You now have truly reusable, content-agnostic prompts.
