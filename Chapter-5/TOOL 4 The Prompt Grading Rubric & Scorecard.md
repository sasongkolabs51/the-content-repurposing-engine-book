## TOOL 4: The Prompt Grading Rubric & Scorecard

**Purpose:** The testing protocol. Run each prompt three times, score each output on Voice Accuracy and Format Correctness, and diagnose any score below 4. This is how you turn "I hope the AI sounds like me" into "I measured it and corrected it."

**Time needed:** 20–25 minutes per prompt (3 generations + scoring + one iteration)

---

### The Rubric

#### Voice Accuracy (1–5)

| Score | Definition | What It Looks Like |
|---|---|---|
| **5** | Indistinguishable from my writing. I'd post it with zero edits. | Hook matches my pattern exactly. Rhythm is right. Vocabulary is mine. Register is right. Close is right. |
| **4** | 90% there. One or two word choices feel slightly off, but the overall voice is clearly mine. | Maybe one corporate word slipped in. Maybe a sentence is slightly too long. But a reader wouldn't notice. |
| **3** | Structure is right, but the language feels "translated." | The argument follows my pattern, but the words aren't mine. A few generic phrases. Rhythm is too uniform. |
| **2** | Recognizably trying to be my voice, but missing the mark. | Hook is generic. Vocabulary is corporate. Register is wrong. Close is a CTA instead of a question. |
| **1** | Generic AI output. Could be anyone. | "In today's fast-paced world…" energy. No trace of my Fingerprint. |

#### Format Correctness (1–5)

| Score | Definition | What It Looks Like |
|---|---|---|
| **5** | Perfect adherence to my Platform Playbook rules. | Exact tweet/slide/word count. Hook pattern matches. Line breaks correct. Close pattern matches. Visual notes present (if applicable). |
| **4** | 90% correct. One minor format element missed. | Maybe the final tweet is a statement instead of a question. Maybe one slide has 3 sentences instead of 2. Easily fixable. |
| **3** | Mostly follows the format, but one structural element is wrong. | Thread is 12 tweets instead of 8. Carousel has no visual notes. Newsletter opens with "Hey friends!" |
| **2** | Vaguely resembles the platform format, but major deviations. | Twitter thread reads like a LinkedIn post. Newsletter is just an expanded tweet thread. |
| **1** | Ignores the format entirely. | Blog post in tweet clothing. No line breaks. No slide structure. |

### The Diagnosis (if either average is below 4)

**If Voice Accuracy < 4:**

☐ Hook pattern wasn't specific enough → Add: "Never open with [generic pattern]. Always open with [your pattern]."
☐ Vocabulary rules too vague → Add explicit "USE these words: [list]. NEVER use these words: [list]."
☐ Rhythm rule unclear → Add: "Sentence length pattern: [short-short-long / etc.]. Vary. Never write 3 sentences of the same length in a row."
☐ Register rule missing → Add: "Emotional register: [X]% [tone], [X]% [tone]. Never sound [anti-register]."
☐ Reference Example wasn't strong enough → Swap for a better post. Add: "Match the CADENCE of this example, not the content."
☐ Missing negative constraint → Add: "Do NOT begin any sentence with 'It is important to note that…' / 'In today's…' / 'We've all…'"
