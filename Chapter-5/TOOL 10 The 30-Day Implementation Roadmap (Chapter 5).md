## TOOL 10: The 30-Day Implementation Roadmap (Chapter 5)

**Purpose:** Build, test, and lock in your prompt library over four weeks.

---

### Week 1: Build the Core Three

- [ ] Complete the **Voice-Preserving Prompt Anatomy Worksheet** (Tool 1). Fill in all five components for Twitter, LinkedIn, and Newsletter.
- [ ] Build your three core prompts using the **Core Prompt Library templates** (Tool 2). Fill in every bracket.
- [ ] Create your **Condensed Voice Constraint Block** (Tool 3). Test it with the "Can an AI follow this?" exercise.
- [ ] Set up your **Reference Example Library** (Tool 8). Paste your 2–3 best posts per platform.
- [ ] **Time commitment:** ~90 minutes total

### Week 2: Test and Score

- [ ] Run each prompt **3 times** against the same Hub. Score each output using the **Prompt Grading Rubric** (Tool 4).
- [ ] For any prompt scoring below 4 on either dimension, use the **Prompt Failure Diagnostic Guide** (Tool 6) to identify the missing constraint. Add it. Retest.
- [ ] Log all changes in the **Prompt Iteration Log** (Tool 7).
- [ ] Run the **Swap Test** (Tool 5) with a different Hub. Fix any topic-specific language.
- [ ] **Time commitment:** ~75 minutes total

### Week 3: Integrate and Expand

- [ ] Complete the **Prompt-Playbook Integration** (Tool 9). Embed your prompts into your Platform Playbook.
- [ ] Build a **TikTok/Reels prompt** using the same five-component anatomy. Test and score it.
- [ ] Run a full content cycle: Hub → 3+ prompts → generate → score → edit → publish.
- [ ] Update the **Iteration Log** with any new fixes.
- [ ] **Time commitment:** ~90 minutes total

### Week 4: Lock In and Automate

- [ ] Run a full content cycle using ONLY your prompt library. No "write it from scratch" fallback.
- [ ] Time your prompt setup for each platform. Target: under 2 minutes per prompt.
- [ ] Time your editing pass for each output. Target: under 5 minutes per asset.
- [ ] Do the **Monthly Prompt Review** (Tool 7). Note what's working, what needs iteration.
- [ ] Refresh your **Reference Examples** (Tool 8) if any new posts outperformed the current ones.
- [ ] **Time commitment:** ~60 minutes total (plus your normal content creation time)

---

4. Have you used the Failure Diagnostic Guide to fix a prompt instead of abandoning AI?

> *If you hit 4+ positive answers, your Voice Amplifier is online. The prompts are doing their job. You're no longer hoping the AI guesses right—you're specifying constraints so tightly that generic output is almost impossible. Chapter 6 is where you run these prompts in parallel and compress a three-hour ordeal into a sixty-minute sprint.*
