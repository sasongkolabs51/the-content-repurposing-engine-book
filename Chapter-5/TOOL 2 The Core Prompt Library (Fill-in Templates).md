## TOOL 2: The Core Prompt Library (Fill-in Templates)

**Purpose:** Your three starter prompts, fully structured and ready to customize. Fill in the brackets with your own content. Save these as permanent templates. For each new pillar piece, you only swap the Hub content and tweak the Constraint.

**Time needed:** 45 minutes to build all three the first time. 2 minutes per prompt to adapt for a new Hub.

### How to Use These Templates

1. **First time:** Fill in ALL brackets. Takes ~45 minutes for all three.
2. **Each new pillar piece:** Copy the prompt. Swap the Hub content in the Constraint section. Tweak the Creative Intent. Takes ~2 minutes per prompt.
3. **Monthly:** Review the Voice Constraint Block. Update if your voice has evolved. Check the Reference Example—is it still your best? Swap if a newer post outperformed it.
