## 8. Quick-Start Session Plan: Build Your Prompt Library in One Focused Block

**Total time:** ~90 minutes. If you can’t do it in one sitting, split at the break marker.

- [ ] **Minute 0–5:** Open your Voice Fingerprint (Chapter 2). Using Section 2 of this toolkit, write your condensed Voice Constraints block.  
- [ ] **Minute 5–10:** Open your Platform-Format Playbook (Chapter 3). Have the Twitter, LinkedIn, and Newsletter sections visible.  
- [ ] **Minute 10–40:** Fill in the three prompt templates (Section 3). Copy-paste your Voice Constraints block into each. Write the Structural Rules using your Playbook. Paste a Reference Example for each platform.  
- [ ] **Minute 40–50:** Pick one recent, well-built Hub. Paste the relevant blocks into each prompt.  
- [ ] **Minute 50–75:** Test all three prompts. For each, generate 3 outputs and score using the Testing Scorecard (Section 4).  
- [ ] **Minute 75–85:** Fix any prompt that scored below 4 on either dimension using the Failure Diagnostic Card (Section 5). Retest once.  
- [ ] **Minute 85–90:** Perform a quick Swap Test (Section 7) with a second Hub if time permits, or schedule it for your next session.  
- [ ] **Wrap-up:** Save your prompt library. Complete the Integration Checklist (Section 6). Pat yourself on the back—you now have a production-grade AI briefing system.
