## 6. Prompt Library Integration Checklist

**Purpose:** Connect your new prompt library to your existing Hub and Playbook so that everything lives in one friction-free flow.

- [ ] My condensed Voice Constraints block (Section 2) is saved and easily copyable.
- [ ] Three core prompt templates (Twitter, LinkedIn, Newsletter) are filled out with my rules and saved.
- [ ] Each template has a clear “Hub: [paste relevant blocks]” section that I can swap per pillar piece.
- [ ] I have added a link to my Platform-Format Playbook inside or next to my prompt library for quick reference.
- [ ] I’ve run the Prompt Testing Scorecard (Section 4) on all three prompts and both averages are ≥ 4.
- [ ] I’ve performed a Swap Test (Section 7) with a different Hub to confirm prompts are content-agnostic.
- [ ] I know where my “Common Failures & Prompt Fixes Card” (Section 5) is and can grab it in under 10 seconds.
