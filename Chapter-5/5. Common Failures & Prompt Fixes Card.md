## 5. Common Failures & Prompt Fixes Card

When output disappoints, use this table to diagnose and fix the prompt immediately. Keep it near your prompt library.

| Symptom | Likely Cause | Prompt Fix |
|---------|--------------|-------------|
| Opening line feels generic: “We’ve all been there…” | Hook constraint too vague or missing a negative example | Add to Voice Constraints: “Never open with a universal statement or rhetorical question. First sentence must be specific and counterintuitive.” Optionally paste a “Bad Example” and “Good Example.” |
| Output reads like a different platform (e.g., Twitter thread is just mini LinkedIn posts) | Structural rules not differentiating formats enough; Reference Example from wrong platform | Add a line: “This is a Twitter thread, not a LinkedIn post. Use line breaks. Do not write multiparagraph tweets.” Ensure Reference Example matches target platform. |
| AI invents a statistic or quote not in my Hub | Missing data constraint | Add to Constraint: “Use ONLY the data and stories provided in the Hub. Do not invent, extrapolate, or add external research. If the Hub lacks a needed element, write [insert data].” |
| All sentences same length, no punch | Rhythm rules missing from Voice Constraints | Add to Voice Constraints: “Vary sentence length. Use occasional one-word or two-word fragments for impact. Break long sentences with a short punchy one.” |
| Tone feels flat, no emotional depth | Emotional register not specified or too broad | Tighten emotional register: “Sound like you’re explaining something to a smart friend over coffee—warm, direct, with one moment of vulnerable self-disclosure per piece.” |
| Output uses banned words despite my list | Lexical ban not strong enough or worded as suggestion | Change to: “You are FORBIDDEN from using these words: [list]. If you use any, regenerate the output.” Also place at the very top of the prompt for emphasis. |
