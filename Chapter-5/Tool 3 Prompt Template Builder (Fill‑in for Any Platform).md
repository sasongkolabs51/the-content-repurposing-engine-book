## Tool 3: Prompt Template Builder (Fill‑in for Any Platform)

**Purpose:** A reusable, fill‑in‑the‑blanks template to construct a Voice-Preserving Prompt for any platform. Build your first three prompts (Twitter, LinkedIn, Newsletter) using this template, then adapt it for additional channels.

**Instructions:** Copy the structure below. Fill in each section for your target platform. Save the completed prompt as a template in your prompt library.

---

**PROMPT FOR [Platform Name]**

**ROLE:**  
You are [insert role description that matches your brand’s tone and expertise level].

**VOICE CONSTRAINTS:**  
[Paste your Condensed Voice Fingerprint Block from Tool 2 here, or reference “see attached Voice Fingerprint” if you’re using a system that supports file uploads.]

**PLATFORM STRUCTURAL RULES:**  
[Insert the specific grammar rules from your Platform-Format Playbook for this platform. Be precise: include hook pattern, length/number of units, line-break cadence, visual cue rules, and closing style.]

**REFERENCE EXAMPLE:**  
Here is an example of my writing on this platform. Model the rhythm, hook style, and overall feel:  
[Paste a high-performing post of yours from this platform.]

**CONSTRAINT:**  
Using only the following Hub blocks: [specify which blocks—Core Thesis, specific Key Story, Data Points, Objections, Quotable Lines—and any other relevant instructions]. Do not invent any data, quotes, or stories. If a required element is missing, insert “[placeholder]” rather than making something up.

**HUB:**  
[Paste the full Hub content below, or paste the specific blocks you want the AI to draw from.]

---

**After completing, run the prompt and score the output using Tool 5.**
