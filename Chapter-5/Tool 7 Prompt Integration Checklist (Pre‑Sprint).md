## Tool 7: Prompt Integration Checklist (Pre‑Sprint)

**Purpose:** A final sweep before you run a batch sprint (Chapter 6). Ensures all three pillars—Hub, Voice Fingerprint, Prompts—are wired together and ready.

- [ ] My Hub for this sprint is fully populated (all five blocks filled).
- [ ] My Voice Fingerprint condensed block is updated and pasted into each prompt template.
- [ ] Each prompt template has a filled Role, Structural Rules, and at least one Reference Example.
- [ ] The Constraint section of each prompt specifies exactly which Hub blocks to draw from.
- [ ] I’ve tested each prompt at least once and it scored 4+ on Voice Accuracy and Format Correctness (or I’ve scheduled a quick test before the sprint).
- [ ] My prompt library is saved in one accessible document, with clear labels for each platform.
- [ ] I have my AI tool open and my Hub ready to paste.

**If any box is unchecked, take 5 minutes to fix it. Sprint speed depends on prompt readiness.**
