## TOOL 8: The Reference Example Library

**Purpose:** Organize your best-performing posts so they're instantly accessible when building or updating prompts. Your Reference Examples are the "show, don't tell" component of every prompt. They need to be curated, labeled, and current.

**Time needed:** 15 minutes to set up. 2 minutes per month to update.

---

### Setup

Create a document or folder called **"Reference Examples — Prompt Library"**. For each platform, paste your 2–3 best posts with metadata.

### Monthly Refresh Rule

On the first Monday of each month:
- Check if any NEW post outperformed your current #1 Reference.
- If yes, swap it in. Update the prompt templates.
- If no, keep the current Reference. Note: "No change needed."
