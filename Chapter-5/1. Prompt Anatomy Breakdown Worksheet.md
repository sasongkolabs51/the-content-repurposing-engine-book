## 1. Prompt Anatomy Breakdown Worksheet

**Purpose:** Learn to see every prompt as a set of five components. Once you can spot a missing piece, generic AI output stops being mysterious.

**Instructions:** Pick a recent prompt you gave an AI that produced disappointing output. Write it here:

*My old prompt:* ________________________________________________

Now, map it against the five essential components. Check which ones were present, even loosely.

| Component | Was it in my prompt? | What I actually gave (or left blank) |
|-----------|----------------------|--------------------------------------|
| **Role** (persona the AI adopts) | ☐ Yes ☐ No | |
| **Tone & Voice Constraints** (specific rules for hooks, rhythm, vocabulary, emotion) | ☐ Yes ☐ No | |
| **Structural Rules** (platform grammar: length, line breaks, slide count, hook pattern) | ☐ Yes ☐ No | |
| **Reference Example** (a pasted example of my best work on that platform) | ☐ Yes ☐ No | |
| **Constraint** (exactly what material to pull from—Hub blocks, not entire transcript) | ☐ Yes ☐ No | |

**Diagnosis:** The components I was missing: ______________________.  
**One immediate fix:** I’ll add ________________________________ to my template.
