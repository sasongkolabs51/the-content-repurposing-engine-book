## TOOL 5: The Translation Quality Checklist

**Purpose:** Run this on every platform asset before publishing. Catches the most common "this is still a summary in disguise" failures.

**Time needed:** 2 minutes per asset

---

### Asset: _______________ Platform: _______________ Date: _______________

| # | Check | Pass / Fail | Notes |
|---|---|---|---|
| 1 | **Hook is platform-native.** Would a native user of THIS platform stop for this opening? Or does it feel imported? | ☐ P ☐ F | |
| 2 | **Structure follows the platform grammar.** (Thread arc for Twitter, slide progression for LinkedIn, visual-beat rhythm for TikTok, letter flow for newsletter.) | ☐ P ☐ F | |
| 3 | **The narrative was REARCHITECTED, not trimmed.** The order of ideas, the emphasis, the entry point—all changed for this platform. | ☐ P ☐ F | |
| 4 | **The hook is DIFFERENT from other platform versions of the same content.** Not the same opening line pasted everywhere. | ☐ P ☐ F | |
| 5 | **The close is platform-appropriate.** (Reflective question for Twitter, engagement prompt for LinkedIn, mic-drop for TikTok, invitation for newsletter.) | ☐ P ☐ F | |
| 6 | **Insight density matches the platform.** (One idea per tweet. One idea per slide. One beat per 5-7 sec on TikTok.) | ☐ P ☐ F | |
| 7 | **Visual / formatting rules followed.** (Line breaks for Twitter, slide design for LinkedIn, overlays for TikTok, paragraph spacing for newsletter.) | ☐ P ☐ F | |
| 8 | **Tone is platform-adjusted.** (More combative on Twitter, more professional-peer on LinkedIn, more physical/energetic on TikTok, most intimate on newsletter.) | ☐ P ☐ F | |
| 9 | **A native viewer would NOT know this was adapted from another platform.** It feels born here. | ☐ P ☐ F | |
| 10 | **My Voice Fingerprint is present.** (Hook style, rhythm, vocabulary, register—all match my documented patterns.) | ☐ P ☐ F | |

**Score:** _____ / 10

**Decision:**
- 9–10: Publish. This is a translation.
- 7–8: Quick fix on the 2–3 fails. Then publish.
- 5–6: Significant rework needed. The structure is still "summary with platform formatting."
- 0–4: Start over. This is distribution wearing a costume. Go back to the Hub and rearchitect.
