## 2. Platform Grammar Deconstruction Worksheet

**Purpose:** Train your eye to see hooks, tension arcs, visual cues, and cadence as teachable rules. Use one high-performing example from each platform—ideally your own best post, but a competitor’s or inspiration’s works too.

**Instructions:** For each platform, paste or describe the content, then break it down using the prompts.

### 2.1 Twitter/X Thread Anatomy

- Post link or description: __________________
- Hook (first tweet): Paste it. What pattern does it use? (bold claim, counterintuitive reveal, open loop, personal confession) __________________
- How does each subsequent tweet end? (question, cliffhanger, bold statement, data point) __________________
- Thread length: ___ tweets. Average sentences per tweet: ___
- Line break pattern: (single breaks after every sentence / breaks between ideas / no breaks) __________________
- Final tweet: How does it close? (reflective question, CTA, punchy one-liner, loop back to hook) __________________
- Voice notes: fragments? Direct address? Colloquialisms? __________________
- **Distilled rule for my Playbook:** (e.g., “Open with a bold claim under 140 characters; each tweet ends with a question or stat; final tweet is a reflective prompt.”)

### 2.2 LinkedIn Carousel Anatomy

- Post link or description: __________________
- Slide 1 (title slide): What does it promise? (specific framework, story, controversial take) __________________
- Narrative arc: (problem → framework → steps → summary → engagement question) Draw the flow: __________________
- Slide count: ___. How much text per slide? (headline + one sentence / short paragraph) __________________
- Personal element: Where does vulnerability or a personal story appear? __________________
- Visual style: (bold text, minimal graphics, screenshots, photos) __________________
- Final slide: What action does it ask for? (comment, save, share, reflect) __________________
- **Distilled rule for my Playbook:** (e.g., “7 slides; title promises a 3-step framework; slide 3 contains a personal failure story; final slide asks a reflective question.”)

### 2.3 TikTok/Reels Script Anatomy

- Video link or description: __________________
- First 1.5 seconds: What’s on screen? (text overlay, bold action, facial expression) What’s said? __________________
- Pattern interrupt frequency: Every ___ seconds something changes (visual cut, text pop-up, camera move). List the types: __________________
- Script structure: (hook → context → insight → payoff → loop) Write the beat outline: __________________
- Text overlay moments: List where text appears and what it says. __________________
- Ending: cliffhanger? CTA? Loopable twist? __________________
- **Distilled rule for my Playbook:** (e.g., “Open with on-screen text that contradicts a common belief; change visual every 5 seconds; end with a ‘watch again’ moment.”)

### 2.4 Newsletter Anatomy

- Newsletter issue or description: __________________
- Subject line: (curiosity gap, personal, listicle, how-to) __________________
- Opening paragraph: How does it hook? (personal story, provocative question, shared moment) __________________
- Body structure: (expanded insight + fresh commentary + personal anecdote / curated links) __________________
- Tone: (like a letter to a friend, teaching voice, rallying cry) __________________
- Closing: How does it end? (question to reply, link to deeper content, gentle nudge) __________________
- **Distilled rule for my Playbook:** (e.g., “Start with a vulnerable personal moment; expand the pillar idea with 2 new examples; close by asking a question that invites replies.”)
