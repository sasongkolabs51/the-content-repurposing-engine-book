## Tool 8: Platform-Native Storytelling Code – Summary Card

**The Platform Code in Five Lines** (print or screenshot):

- **Platforms are languages, not buckets.** Each has a specific narrative grammar your content must speak.
- **Twitter threads are tension engines.** Hook, tension, payoff—every tweet must earn the next click.
- **LinkedIn carousels are teaching frameworks.** Problem → story → framework → reflective prompt.
- **TikTok scripts are visual-verbal sequences.** A pattern interrupt every 5–7 seconds, text overlays as second hooks.
- **Newsletters are depth conversations.** Personal, episodic, and rich—readers opted in for more than a summary.

**The Translation Instinct:** When you see a pillar idea, your first thought shouldn’t be “How do I cut this down?” but “What’s the native experience I want to build on [platform]?”
